# 运营管理层 (operations/)

> **定位**: 基于制造数据的运营管理、可视化展示与边缘采集
> **包含模块**: kanban, reporting, document, energy, iiot（共5个）
> **部署顺序**: 依赖基础层和制造层模块就绪后部署

本层模块消费制造层产生的数据，提供管理看板、报表分析、文档管理、能源监控和IIoT边缘采集能力。

| 模块 | 端口 | 说明 |
|------|------|------|
| kanban | 8074,8080 | 生产/品质/设备/安灯大屏 |
| reporting | 8091 | 自定义报表、导出、定时分发 |
| document | 8093 | 图纸、文档、审批、检索 |
| energy | 8089 | 能耗采集、能效分析、碳排 |
| iiot | 8090 | 边缘网关、协议适配、数据采集 |
