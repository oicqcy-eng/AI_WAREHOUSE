# 基础层 (base/)

> **定位**: 所有上层模块依赖的基础服务与主数据
> **包含模块**: system（系统管理）、master-data（基础资料）、barcode（条码/RFID）
> **部署顺序**: ⭐ 优先部署，上层模块依赖本层服务

本层模块提供企业级基础能力，包括用户认证与权限体系、编码规则与主数据管理、条码/RFID 标签管理。
在部署任何制造或运营模块之前，必须先确保本层服务正常运行。

| 模块 | 端口 | 数据库 | 说明 |
|------|------|--------|------|
| system | 8086 | system_db | 用户、角色、权限、审计、通知 |
| master-data | 8071 | master_db | 编码、客户、供应商、员工、部门、工序 |
| barcode | 8076 | barcode_db | 条码规则、打印、扫描配置 |
