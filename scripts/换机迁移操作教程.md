# 换机迁移操作教程（照着做即可）

> **用途**：换新电脑时，把整套 AI-WAREHOUSE 工作环境迁移过去。
> **配套脚本**：`scripts/backup-portable.ps1`（旧电脑备份）、`scripts/restore-new-pc.ps1`（新电脑还原）。
> **适用**：Windows 电脑。全程约 20 分钟，大部分步骤照抄命令即可。

---

## ⚠️ 先讲最重要的一点：数据库不阻塞还原

**还原成功 = 仓库代码 + 记忆 + 客户资料都放到了新电脑**，和你能不能连上数据库**没有任何关系**。

- 还原脚本**只复制文件，不连库**。就算旧公司的 MES/U9 库一个都连不上，还原照样 100% 成功。
- 数据库是你**之后**要用的"业务连接"。换新公司/新项目 → 你只会连**新的库**，跟旧库无关（详见文末《五、换成新公司的库怎么改》）。
- 所以别把"验证连库"当成还原是否成功的标准——它的标准是：**文件在不在**（见《四、怎么判断还原成功》）。

## 一、旧电脑：换机前的准备（约 5 分钟）

### 1. 把最新代码推到 GitHub（保证云端是最新）

```powershell
cd D:\AI_WAREHOUSE
git add -A
git commit -m "换机前备份"
git push
```

### 2. 一键备份"仓库外依赖"

```powershell
powershell -ExecutionPolicy Bypass -File scripts\backup-portable.ps1
```

会生成一个 zip，例如：`AI-WAREHOUSE-portable-20260823-010027.zip`（约 80MB），里面包含：
- **Claude 记忆**（40+ 条工作规则，不备份则新电脑助手不认你的习惯）
- **DB 凭据** `db.local.json`
- **客户原始资料**（各厂 raw/ 原件、inbox/ 输入、截图）

> 可选参数：`-OutDir E:\迁移` 指定输出目录；`-Name 我的备份` 指定文件名。

### 3. 把 zip 拷到新电脑

U 盘 / 移动硬盘 / 微信文件传输 / 私有网盘均可（zip 含数据库账号密码，**别传公共网盘**）。

## 二、新电脑：装基础软件（约 5 分钟）

### 必须装
| 软件 | 装法 | 说明 |
|------|------|------|
| **Git** | 运行 `winget install --id Git.Git -e` | 拉仓库用 |
| **Node.js**（自带 npm） | 运行 `winget install --id OpenJS.NodeJS.LTS -e` | 工具脚本依赖 |

> 不想敲命令？直接双击安装包也行：git-scm.com 下载 Git、nodejs.org 下载 LTS 版。装完**重开一个终端**（让 PATH 生效）。
> 也可以跳过这步——**还原脚本自带环境预检**，检测到缺失会提示装什么、甚至 `-AutoInstall` 自动装（见下面第三步）。

### 推荐装（可选）
- **Claude Code**：继续用 AI 工作流（记忆在这套仓库里，还原后自动接上）。安装方法见 claude 官方文档，或还原完成后在仓库目录开个会话让我带你装。
- 解压工具（Windows 自带就行）。

## 三、新电脑：还原（约 5 分钟）

### 1. 拉取仓库（含全部历史）

```powershell
cd D:\
git clone https://github.com/oicqcy-eng/AI_WAREHOUSE.git
cd AI_WAREHOUSE
```

### 2. 一键还原（含环境预检）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\restore-new-pc.ps1 -ZipPath <刚才的zip路径>
```

脚本会依次：
1. **环境预检**：检测 git / node / npm / 依赖是否就绪，缺什么直接提示安装命令；
2. 还原 **Claude 记忆** → `~\.claude\projects\d--AI-WAREHOUSE\memory\`
3. 还原 **DB 凭据** → `agent\mes-implement-expert\config\db.local.json`
4. 还原 **客户资料** → 各 raw/、inbox/ 原位

> 环境缺失时：按它提示的 winget 命令装完，重开终端再跑一次；或直接加 `-AutoInstall` 让它自动装。
> 只想先体检不还原：加 `-SkipRestore`。

### 3. 重建 Node 依赖

```powershell
cd tmp
npm install
```

### ✅ 还原到此完成，可以开始用了。

## 四、怎么判断还原成功（不靠连库）

| 检查项 | 命令 | 通过标准 |
|--------|------|---------|
| 仓库有历史 | `git log --oneline | head` | 能看到以前的 commit（比如"换机前备份"） |
| 记忆还原 | `dir %USERPROFILE%\.claude\projects\d--AI-WAREHOUSE\memory` | 有几十个 .md 文件 |
| 凭据还原 | `dir agent\mes-implement-expert\config\db.local.json` | 文件存在 |
| 客户资料还原 | 随便看一个 `delivery\projects\...\raw\` | 有文件 |
| npm 依赖 | `dir tmp\node_modules\mssql` | 目录存在 |

以上**前 4 项全过 = 还原成功**，跟数据库连不连得上无关。

## 五、换成新公司的数据库怎么改（重点）

你的库连接配置在 `agent\mes-implement-expert\config\db.local.json`（**已经随备份还原了**，内容是旧公司的）。新公司/新项目要连的是新库，改法：

### 1. 打开该文件，看结构

```json
{
  "profiles": {
    "home": { "server": "...", "port": 1433, "database": "...", "user": "...", "password": "...", "options": {...} },
    "cq":   { "server": "...", "port": 1433, "database": "...", "user": "...", "password": "...", "options": {...} }
  }
}
```

每个 `xxx` 就是一套库连接（profile），跑工具时用 `--profile xxx` 指定，默认取第一个。

### 2. 两种改法，任选

**A. 追加新库（保留旧的以备查询）**：在 `profiles` 里加一段，例如：

```json
"newcompany": {
  "server": "新公司数据库IP",
  "port": 1433,
  "database": "新库名",
  "user": "只读账号",
  "password": "密码",
  "options": { "encrypt": false, "trustServerCertificate": true }
}
```

然后用 `node tools/query-mes.js 文件 --profile newcompany ...`。

**B. 只保留新库**：把整个 `profiles` 内容替换成新公司的一套，旧的全删掉。

> 凭据格式和所有可用参数参考 `agent\mes-implement-expert\config\db.local.example.json`（模板，已入库）。

### 3. 验证新库连通（这一步才需要连库）

```powershell
node agent\mes-implement-expert\tools\query-mes.js -q "SELECT 1" --profile newcompany
```

看到「✅ 返回」即连通。连不上时检查：IP/端口/库名/账号密码是否正确、新电脑是否在公司内网/已连 VPN、数据库服务器防火墙是否放行你的 IP。

## 六、常见问题（FAQ）

**Q1：还原时提示连不上数据库，是不是失败了？**
不是。还原脚本根本不连库，这个提示只出现在你**主动验证**时。文件还原成功与否看《四》。

**Q2：备份 zip 丢了 / 是旧的怎么办？**
不用备份 zip 也能还原大部分——仓库在 GitHub，`git clone` 就有全部代码和历史。缺的只有：记忆（旧电脑还能再跑一次备份）、凭据（按新库手填）、客户资料（旧电脑重新拷）。**最重要的代码永远在 GitHub，丢不了。**

**Q3：新电脑不在旧公司内网，旧库连不上？**
正常且无关紧要。你是要连**新公司**的库，按《五》改配置即可。

**Q4：npm install 很慢或失败？**
可能是网络问题。重试；或用国内镜像 `npm config set registry https://registry.npmmirror.com` 后再装。

**Q5：装完 Node 后命令找不到？**
重开终端（PATH 刷新）。还不行就注销/重启。

**Q6：想让 AI 全程帮我操作？**
新电脑装好 Git + Node 后，在仓库目录运行 `claude`，打开会话说一句「按 scripts\换机迁移操作教程.md 帮我还原环境」。我会检测、安装、还原、验证，一步步带你走完。
