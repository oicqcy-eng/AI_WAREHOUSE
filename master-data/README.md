# 基础数据管理模块

> **模块说明**: 企业主数据管理 — 编码体系、客户/供应商、员工、部门/工序/设备类型等基础资料
> **服务端口**: 8071 (HTTP)
> **数据库**: master_db

## 管理范围
| 数据类型 | 说明 | 编码规则 |
|---------|------|---------|
| 物料编码 | 所有物料的唯一编码 | MAT-{类别}-{序号} |
| 客户 | 客户基本信息与等级 | CUS-{序号} |
| 供应商 | 供应商资质与评估 | SUP-{序号} |
| 员工 | 人员信息与技能标签 | EMP-{部门}-{序号} |
| 部门 | 组织架构树 | DEPT-{层级} |
| 工序 | 工序定义与标准工时 | PROC-{序号} |
| 设备类型 | 设备分类与参数模板 | EQTP-{序号} |
| 质检标准 | 检验项目与标准值 | QC-{序号} |

## 快速操作
```bash
docker compose -f deploy/docker-compose.yml up -d
curl http://localhost:8071/health
```
