# AI智能层 (ai/)

> **定位**: 独立于 MES 的 AI 能力，提供模型推理、GPU管理、向量存储与模型训练
> **包含模块**: serving, gpu, vector-db, training（共4个）
> **部署顺序**: 按需部署，与制造层解耦

本层是平台的差异化优势，引入大模型推理、GPU集群管理、向量数据库和分布式训练能力。
可独立于 MES 部署，也可与制造层联动（如 AI 辅助质检、智能排程等场景）。

| 模块 | 端口 | 说明 |
|------|------|------|
| serving | 8000,8001,8002 | vLLM/Triton 模型推理 |
| gpu | 9400 | DCGM GPU 监控与调度 |
| vector-db | 19530 | Milvus/Qdrant 向量数据库 |
| training | - | 分布式训练任务管理 |
