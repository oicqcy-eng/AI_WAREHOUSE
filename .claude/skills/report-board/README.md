# report-board — 控制台风汇报板

> 生成模块化 HTML 汇报版面（投影用）：深墨蓝控制台底 + 青绿信号 + 琥珀警示 + 等宽日期编号。

## 用法

复制 `templates/control-board-template.html` 为 `<主题>.html`，按模板内注释替换 `【】` 占位符、按需删减模块。详见 [SKILL.md](SKILL.md)。

## 实例

| 实例 | 位置 |
|------|------|
