## 维度 4：数采设备类型与采集方案 ★重点

### 现状（已沉淀）

**三厂小簧数采（106台）**：
- 已安装+通电（S1）：37台，可调试
- 已安装+未安装（S2）：1台
- 未安装+通电（S3）：43台，点位未提供
- 未安装+未安装（S4）：25台

**采集方式分类**：
- 系统对接（ModbusTCP/S7/OPC UA）：约60台
- IO采集（开关机/运行状态）：约34台（压簧机/异形簧机/线成型机等）
- 串口采集：少量

**共性设备类型（可复用）**：

| 设备类型 | 出现厂区 | 采集方式 | 常见痛点 | 复用价值 |
|---------|---------|---------|---------|---------|
| 淬火线 | 三厂（材料）✅ | ModbusTCP | DB120地址不对 | ⭐⭐⭐ |
| 回火炉 | 三厂/一厂/重庆 | ModbusTCP/仪表采集 | IP错误/协议异常 | ⭐⭐⭐ |
| 端面磨床 | 三厂/一厂/重庆 | 系统对接 | 串口线损坏/柜门打不开 | ⭐⭐ |
| 压簧机 | 三厂/一厂/重庆 | IO采集或ModbusTCP | 专用控制器需厂家开放协议 | ⭐⭐⭐ |
| 异形簧机 | 三厂/一厂 | ModbusTCP | 专用控制器/PC机双类型 | ⭐⭐ |
| 线成型机 | 三厂/一厂 | IO采集或ModbusTCP | coolmay控制器通讯问题 | ⭐⭐ |
| 抛丸机 | 三厂/一厂/重庆 | S7协议 | 需加装交换机/开放S7协议 | ⭐⭐ |
| 探伤机 | 三厂（材料）✅ | 开发中 | 需确认鼎捷vs厂家开发 | ⭐⭐ |
| 电子式拉压试验机 | 三厂 | MySQL/CSV输出 | 厂家数据库不兼容 | ⭐⭐ |
| 倒角机 | 三厂 | MC协议 | 需开放MC协议和接口信息 | ⭐ |
| 弹簧立定机 | 三厂 | 系统对接 | 无遗留问题 | ⭐ |

### 待盘点（核心产出物）

| 输出物 | 说明 |
|--------|------|
| **《数采设备类型字典》** | 设备类型 → 采集方式 → 协议 → 前置条件 → 常见问题 → 解决路径（全流程） |
| **《数采需求调研选择题》** | 把"填空题"变成"选择题"，新项目进场先做问卷 |
| **《设备采集方案速查卡》** | 按设备类型，一页纸给出推荐方案+注意事项 |
| **《协议开放要求模板》** | 给设备厂家的正式函件模板（ModbusTCP/S7/OPC UA/MC等） |

## 复用场景举例

### 场景1：新厂区数采项目进场
**现在**：从头调研每台设备，做填空题
**复用后**：
1. 拿《数采设备类型字典》对照新厂区设备清单
2. 发《数采需求调研选择题》给客户填写
3. 根据选择题结果，直接给出采集方案建议
4. 需要厂家配合的，发《协议开放要求模板》

### 场景2：新项目基础资料准备
**现在**：从头设计编码规则
**复用后**：
1. 参考《基础资料编码规范白皮书》
2. 直接套用《基础资料导入模板集》
3. 用《基础资料质量检查清单》校验

### 场景3：运维报错处理
**现在**：每次报错重新排查
**复用后**：
1. 截图扔inbox，OCR识别报错文字
2. 匹配《运维排障知识库》
3. 返回处理方案+预防措施
