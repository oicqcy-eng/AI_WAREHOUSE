## 附录A：各协议技术注意事项（内部参考）

### A.1 ModbusTCP协议

| 检查项 | 要求 | 备注 |
|--------|------|------|
| IP地址 | 静态IP，避免DHCP | 需与设备厂家确认 |
| 端口 | 502（标准） | 如有修改需确认 |
| 从站地址 | 通常为1 | 需确认 |
| 字节序 | 大端/小端需确认 | 否则数据错乱 |
| 连接数 | 确认设备最大连接数 | 一般支持1-4个 |

**常见坑**：
- 部分国产PLC默认关闭ModbusTCP服务，需厂家开启
- 寄存器地址可能为0-based或1-based，需确认
- 浮点数字节序可能不同，需测试验证

### A.2 S7协议（西门子PLC）

| 检查项 | 要求 | 备注 |
|--------|------|------|
| 优化块访问 | **必须取消**（DB块取消Optimized Block Access） | ⚠️ 最大坑点 |
| TSAP本地 | 需配置（如10.00） | - |
| TSAP远程 | 需配置（如10.01） | - |
| Rack/Slot | 通常为0/0或0/1 | 根据PLC型号 |
| 访问权限 | 需设置为允许PUT/GET | 在PLC属性中配置 |

**常见坑**：
- 西门子1200/1500默认启用优化块访问，S7协议无法读取绝对地址
- 必须在STEP 7/TIA Portal中取消"优化的块访问"
- 可能需要厂家重新下载程序

### A.3 OPC UA协议

| 检查项 | 要求 | 备注 |
|--------|------|------|
| 端点URL | opc.tcp://{IP}:4840/{path} | 需确认路径 |
| 安全策略 | None / Basic128Rsa15 / Basic256 | 需确认支持级别 |
| 认证方式 | 匿名 / 用户名密码 / 证书 | 数采通常用匿名 |
| 证书互信 | 需将客户端证书导入服务端信任列表 | ⚠️ 常卡住 |

**常见坑**：
- OPC UA证书互信配置复杂，需厂家配合
- 部分厂家使用Kepware等软件中转，需额外确认
- 命名空间URI需确认

### A.4 串口通讯（RS232/RS485）

| 检查项 | 要求 | 备注 |
|--------|------|------|
| 波特率 | 9600/19200/38400等 | 需确认 |
| 数据位 | 8 | 固定 |
| 校验位 | None/Even/Odd | 需确认 |
| 停止位 | 1 | 固定 |
| 从站地址 | 通常为1 | 多设备需确认 |
| 隔离要求 | **必须使用隔离型RS485转换器** | 防雷抗干扰 |
| 总线拓扑 | **手拉手，禁止星型** | 抗干扰要求 |

**常见坑**：
- RS485总线长度限制（一般≤1200m）
- 多设备地址冲突
- 未使用隔离转换器导致雷击损坏

## 附录C：厂家沟通话术指南（对内参考）

### C.1 厂家以"协议保密"为由拒绝

**应对话术**：
> "我们理解贵司对核心工艺参数的保护需求。此次数据采集**仅限只读访问**，不涉及任何写入操作，不会影响设备运行安全和工艺保密。采集的数据仅用于华纬内部生产管理和质量追溯，不会外传。如贵司有顾虑，我们可以签署保密协议。"

### C.2 厂家以"需要加钱"为由拒绝

**应对话术**：
> "协议开放是设备标配功能，不应该额外收费。如果确实需要开发，我们可以协商合理的费用。但请告知具体开发内容和工时，我们评估后决定是否推进。"

### C.3 厂家表示"设备老旧不支持"

**应对话术**：
> "了解设备较老。请问是否可以通过加装外围采集模块（如IO采集盒）实现？我们可承担硬件费用。或者是否有PLC升级方案？"

### C.4 厂家回复周期长

**应对话术**：
> "理解贵司需要时间确认。鉴于项目进度紧张，能否先提供基础点位信息（运行状态+产量），高级点位后续补充？我们先从基础开始推进。"

## 附录D：常见问题排查清单

| 问题现象 | 可能原因 | 排查步骤 | 解决方案 |
|----------|---------|---------|---------|
| 连接超时 | IP/端口错误、防火墙拦截 | 1. ping测试网络连通性<br>2. telnet测试端口<br>3. 检查防火墙规则 | 确认IP/端口，开放防火墙 |
| 读取数据为0或异常 | 字节序不对、寄存器地址错误 | 1. 确认big/little endian<br>2. 确认0-based还是1-based<br>3. 用Modbus Poll测试 | 调整字节序或寄存器偏移 |
| S7协议连接失败 | 优化块访问未关闭 | 1. 检查PLC DB块属性<br>2. 确认是否勾选"优化的块访问" | 在TIA Portal中取消该选项 |
| OPC UA证书报错 | 证书未信任 | 1. 导出客户端证书<br>2. 导入服务端信任列表 | 厂家配合配置证书互信 |
| 数据刷新慢 | 采集周期设置过长 | 检查网关扫描周期配置 | 缩短至1-5秒 |
| 报警代码无法解读 | 厂家未提供代码对照表 | 要求厂家提供报警代码表 | 建立报警代码映射表 |
