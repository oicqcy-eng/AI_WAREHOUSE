# MES 主数据编码规范（行业经验 L1）

> 从三厂小簧项目提炼的**可跨项目复用**的 MES 主数据编码体系。
> 适用于弹簧/汽配类离散制造 MES 规划，供后续项目参考。

## 工序编码体系

三段式编码，按生产阶段分段：

| 段 | 前缀 | 含义 | 实例 |
|----|------|------|------|
| 检验段 | Q | 检验工序 | Q1 来料检验、Q2 过程自验、Q3 过程巡验、Q4 成品检验、Q5 周期性检验 |
| 前段 | A | 成型前工序 | A01 卷簧、A02-A07 成型1-6、A08 卷簧放钢丝 |
| 中段 | B | 加工处理工序 | B01 去应力退火、B02 定型、B03 端面磨削、B04 精磨、B05 内倒角、B06 外倒角、B07 喷丸0.6 |

**关键约定**: "工序标黄 = 制样截止工序"（区分制样与批量工序）。

## 设备编码体系

按设备功能分段：

| 前缀 | 含义 | 实例 |
|------|------|------|
| XA | 印漆/移印 | XA01 移印机 |
| XB | 电泳线 | XB06 全自动磷化除渣机 |
| XJ | 卷簧 | XJ01 压簧机、XJ07 多功能电脑弹簧机 |

## 组织群组编码体系（SCXH 示例）

层级式群组编码，前缀含厂区标识：

```
SCXH-SC001   管理组（总经理/生产经理）
SCXH-SC1xx   车间生产组（一/二/气门簧组）
SCXH-SC2xx   花式车间组（生产/包装发黑）
SCXH-PLN001  计划组
SCXH-QC001   品质组
SCXH-TEC001  技术组
SCXH-EQP001  设备组
SCXH-LOG001  物流辅助组
```

## 主数据字段口径要点

- 仓库：编号(VARCHAR2 20)、名称(50)、类型（线边仓/成品仓/报废仓）
- 区域：编号、名称、部门、分类（基底区域/离散型区域/生产线/其他）
- 数据库字段类型倾向 Oracle VARCHAR2

## 可复用价值

- 编码**分段 + 前缀语义化**，便于归类与检索
- 群组编码**层级化**（管理→生产→辅助），支撑权限继承
- 工序编码与设备/群组可交叉关联（设备台账含对应工序字段）
