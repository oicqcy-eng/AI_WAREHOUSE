# 数采设备类型字典（基于数据库实测）

> **数据来源**: `JS_SHUCAI_POINT_META` + `shucaibasis` + `v_wendinggan_shucai_detail`
> **生成日期**: 2026-09-16
> **用途**: 新项目数采调研时，从"填空题"变成"选择题"

---

## 一、数采点位命名规范（已沉淀）

### 1.1 标签名规律

| 前缀 | 含义 | 示例 | 出现频次 |
|------|------|------|---------|
| `JS_*` | 金晟工厂 | `JS_1DTJ_TG1` | 159个 |
| `W*` | 未分配厂区（待关联设备） | `WP02`, `WV01` | 818个 |
| `1L*`, `2L*`, `3L*`... | 产线编号 | `1LRCX_TG1` (1号线热成型) | 按产线 |

### 1.2 序号规律

| 后缀 | 含义 | 示例 |
|------|------|------|
| `_TG1` | 运行状态 | `JS_1DTJ_TG1` = 端头机运行状态 |
| `_TG2` | 产量计数 | `JS_1DTJ_TG2` = 端头机产量 |
| `_TG3` | 节拍 | `JS_1DTJ_TG3` = 端头机节拍 |
| `_TG4` | 联网状态 | `JS_1DTJ_TG4` = 端头机联网状态 |

**结论**: 标准设备通常采集**4个核心指标**：运行状态 + 产量 + 节拍 + 联网状态

### 1.3 数值类型

| value_type | 含义 | 处理逻辑 | 示例 |
|-----------|------|---------|------|
| `status` | 开关量状态 | 1=正常/运行，0=异常/停止 | 运行状态、报警信号 |
| `counter` | 累计计数 | 直接读取，需考虑溢出 | 产量、计数 |
| `analog` | 模拟量 | 可能需要除系数（如除10） | 温度、压力 |

## 二、设备类型→采集点位标准模板

### 2.1 热成型机（22个点位）

| 点位序号 | 采集项 | 数值类型 | 单位 | 数据格式 |
|---------|--------|---------|------|---------|
| TG1-TG2 | 日产量/总产量 | counter | 件 | 单位：件 |
| TG3-TG11 | 液压站油温高/低报警、泵过载、滤油器堵 | status | - | 1=故障，0=正常 |
| TG12-TG15 | 泵压力/流量 | analog | - | 无换算 |
| TG16-TG22 | 泵运行状态、手自动指示、报警指示 | status | - | 1=运行/自动，0=停止/手动 |

**复用建议**: 新项目热成型机直接套用这22个点位

### 2.2 回火炉（29个点位）

| 点位序号 | 采集项 | 数值类型 | 单位 | 数据格式 |
|---------|--------|---------|------|---------|
| TG1-TG4 | 各加热区温度 | analog | ℃ | **数值需除10** |
| TG5-TG8 | 各加热区超温报警 | status | - | 1=故障，0=正常 |
| TG9-TG12 | 各加热区低温报警 | status | - | 1=故障，0=正常 |
| TG13 | 燃气总量 | null | 立方 | 无换算 |
| TG14-TG17 | 各区温度设定值 | analog | ℃ | **数值需除10** |
| TG18-TG29 | 工艺时间、链速度、急停、风机状态 | mixed | - | 见具体点位 |

**复用建议**: 回火炉标准采集**温度+报警+状态**三类，温度需乘系数0.1

### 2.3 端头机（4个点位）

| 点位序号 | 采集项 | 数值类型 | 单位 | 说明 |
|---------|--------|---------|------|------|
| TG1 | 运行状态 | status | - | 1=运行，0=停止 |
| TG2 | 产量 | counter | 件 | 单位：件 |
| TG3 | 节拍 | analog | - | 单位：件/时 |
| TG4 | 联网状态 | status | - | 1=在线，0=离线 |

**复用建议**: 最简单的设备，4个点位全覆盖

### 2.4 硫化线（4个点位/条线）

| 点位序号 | 采集项 | 数值类型 | 单位 | 说明 |
|---------|--------|---------|------|------|
| TG1 | 产量 | counter | 件 | 单位：件 |
| TG2 | 节拍 | counter | 件/时 | 单位：件/时 |
| TG3 | 联网状态 | status | - | 1=在线，0=离线 |
| TG4 | 运行状态 | status | - | 1=运行，0=停止 |

**复用建议**: 每条硫化线统一4点位，可按产线数量×4估算

### 2.5 抛丸机（126个点位/台）

**注意**: 抛丸机点位最多（126个），包含大量配方参数，**非标准模板**

标准采集项（必须）：
- 运行状态、故障、计数值、累积计数、运行时间

扩展采集项（可选）：
- 各抛丸器状态（6组Y/D）、供丸状态、分离器状态、风机状态

**复用建议**: 新项目抛丸机先问清楚需要哪些点位，不要默认全采

## 四、数采需求调研选择题模板

```

   ○ 热成型机
   ○ 回火炉
   ○ 端头机
   ○ 压簧机
   ○ 异形簧机
   ○ 线成型机
   ○ 抛丸机
   ○ 硫化线
   ○ 其他：______

□ 2. 设备数量：______台

□ 3. 设备厂家：______
□ 4. 控制器品牌/型号：______
```

### 4.2 采集需求（多选）

```
□ 5. 需要采集哪些数据？（可多选）
   □ 运行状态（运行/停止/故障）
   □ 产量计数
   □ 生产节拍
   □ 温度/压力等模拟量
   □ 报警信号
   □ 其他：______

□ 6. 数据采集频率要求：
   ○ 实时（秒级）
   ○ 分钟级（1-5分钟）
   ○ 小时级
   ○ 只需累计产量

□ 7. 是否需要与MES自动对接出站？
   ○ 是（需配置自动出站规则）
   ○ 否（只读数据看板）
```

### 4.3 网络与接口（必选）

```
□ 8. 设备是否有网口？
   ○ 有（可提供IP地址）
   ○ 无（需加装交换机）
   ○ 不确定

□ 9. 设备协议类型：
   ○ ModbusTCP
   ○ S7协议（西门子）
   ○ OPC UA
   ○ 串口（RS232/RS485）
   ○ 不确定/ unknown

□ 10. 厂家是否配合开放协议？
    ○ 是，已提供点位表
    ○ 是，需协调
    ○ 否，需华纬督促
    ○ 不确定
```

## 五、数据库表结构参考

### 5.1 JS_SHUCAI_POINT_META（点位元数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| point_id | int | 主键 |
| plant_code | nvarchar | 工厂代码（如JINSHENG） |
| plant_name | nvarchar | 工厂名称 |
| line_name | nvarchar | 产线名称 |
| equipment_name | nvarchar | 设备名称 |
| equipment_no | nvarchar | 设备编号 |
| tag_name | nvarchar | 标签名（如JS_1DTJ_TG1） |
| tag_name_key | nvarchar | 标签键（小写） |
| collect_item_name | nvarchar | 采集项名称 |
| data_format_desc | nvarchar | 数据格式说明 |
| value_type | nvarchar | 数值类型(status/counter/analog) |
| unit_name | nvarchar | 单位 |
| enabled_flag | bit | 是否启用 |

### 5.2 shucaibasis（采集点位配置）

| 字段 | 类型 | 说明 |
|------|------|------|
| TagName | nvarchar | 标签名 |
| Description | nvarchar | 描述 |
| Equipmentno | nvarchar | 设备编号（**大量为空，需关联**） |
| Equipmentname | nvarchar | 设备名称 |
| ParametersName | varchar | 参数名 |
| StandardPV | varchar | 标准值 |
| MaxPV/MinPV | varchar | 最大/最小值 |

## 六、复用场景

### 场景1：新项目数采调研
1. 打印《数采需求调研选择题》发给客户
2. 客户勾选后，直接对应本字典的点位模板
3. 生成《数采点位配置表》导入系统

### 场景2：数采点位缺失排查
1. 查询 `v_wendinggan_shucai_detail` 查看已配置点位
2. 对比本字典标准模板，找出缺失项
3. 生成《点位补齐清单》

### 场景3：新设备类型接入
1. 参考本字典中相似设备的点位设计
2. 新增点位时遵循 `工厂_产线_设备_TG序号` 命名规范
3. 记录到 `JS_SHUCAI_POINT_META` 表
