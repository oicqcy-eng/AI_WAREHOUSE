## 部署策略

| 环境 | 策略 | 说明 |
|------|------|------|
| dev | Docker Compose | 单机部署，快速迭代 |
| staging | K8s (单节点) | 验证部署流程与配置 |
| prod | K8s (多节点 HA) | 高可用，自动扩缩容 |

## 高可用设计

- **数据库**: PostgreSQL 主从复制 + Patroni 自动故障转移
- **缓存**: Redis Sentinel / Cluster
- **AI 推理**: 多副本 + 负载均衡
- **网关**: Nginx 多节点 + Keepalived VIP
- **监控**: Prometheus HA + Alertmanager 集群

## 灾备策略

| 层级 | RTO | RPO | 方案 |
|------|-----|-----|------|
| 热备 | <5min | <1min | 多副本 + 自动故障转移 |
| 温备 | <30min | <24h | 每日全量备份 + WAL 归档 |
| 冷备 | <4h | <7d | 每周异地备份 |
