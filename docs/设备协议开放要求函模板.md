# 设备协议开放要求函（标准模板）

> **版本**: V1.0 (2026-09-16)
> **使用场景**: 新项目数采进场后，向设备厂家正式发函要求开放通讯协议
> **复用价值**: 每次发函节省1-2小时编写时间

---

## 模板一：ModbusTCP协议开放要求函（通用版）

---

**致：{设备厂家名称}**

**关于：{设备名称}数据通讯协议开放及点位表提供要求函**

尊敬的{厂家联系人}：

您好！

我司{华纬科技}与{鼎捷软件}合作实施MES系统项目，需要接入贵司提供的{设备名称}数据进行生产实时采集。为确保数据采集顺利，请贵司协助提供以下信息：

### 一、协议开放要求

| 序号 | 要求项 | 详细说明 | 备注 |
|------|--------|----------|------|
| 1 | 通讯协议 | ModbusTCP | 如不支持请告知替代方案 |
| 2 | 通讯接口 | RJ45网口 | 请确认设备是否有预留网口 |
| 3 | IP地址 | {已分配IP或请提供} | 静态IP，避免DHCP频繁变更 |
| 4 | 端口号 | 502（标准ModbusTCP端口） | 如有特殊端口请说明 |
| 5 | 访问权限 | 只读访问即可 | 不涉及设备控制 |

### 二、点位表要求

请提供以下格式的点位表（Excel或文本均可）：

| Tag名称 | 寄存器地址 | 数据类型 | 单位 | 描述 | 读写属性 |
|---------|-----------|---------|------|------|---------|
| 示例：RunStatus | 40001 | Int16 | - | 运行状态(1=运行/0=停止) | 只读 |
| 示例：ProductCount | 40002 | Int32 | 件 | 累计产量 | 只读 |

**必需采集的点位（至少包含）：**
- [ ] 运行状态（运行/停止/故障）
- [ ] 产量计数
- [ ] 生产节拍（可选）
- [ ] 关键报警信号（如故障代码）
- [ ] 其他：_________

### 三、技术要求

1. **协议版本**: ModbusTCP RTU over TCP/IP
2. **字节序**: 请说明是大端(byte order)还是小端
3. **字顺序**: 请说明是ABCD还是DCBA
4. **浮点数格式**: 如需传输浮点数，请说明IEEE754格式
5. **轮询周期**: 建议1-5秒，可根据实际需求调整

### 四、联系方式

| 项目 | 内容 |
|------|------|
| 对接人 | {华纬对接人姓名} |
| 电话 | {联系电话} |
| 邮箱 | {邮箱地址} |
| 现场实施时间 | {预计进场时间} |
| 技术要求文档 | 见附件 |

### 五、回复要求

请贵司在收到本函后**3个工作日内**书面回复：
1. 是否支持ModbusTCP协议
2. 如不支持，提供支持的替代协议（如OPC UA、S7等）
3. 提供完整点位表
4. 指定技术对接人及联系方式

如有任何疑问，请及时与我司联系。

此致

敬礼！

**{华纬科技名称}**
**{日期：YYYY-MM-DD}**

---

尊敬的{厂家联系人}：

您好！

我司需接入贵司{设备名称}进行数据采集，设备PLC为西门子品牌，请协助开放S7通讯协议。

### 一、技术要求

| 项目 | 要求 |
|------|------|
| PLC型号 | {西门子S7-300/400/1200/1500} |
| 通讯协议 | S7 Protocol (ISO-on-TCP) |
| IP地址 | {填写IP地址} |
| 端口 | 102（S7默认端口） |
| TSAP本地 | {填写TSAP本地地址} |
| TSAP远程 | {填写TSAP远程地址} |
| rack | 0 |
| slot | {根据PLC型号填写} |

### 二、数据区访问权限

请确认以下数据区可访问：
- [ ] DB块（数据块）
- [ ] M区（ Merker）
- [ ] I区（输入）
- [ ] Q区（输出）
- [ ] V区（变量）

### 三、必需采集点位

| Tag名称 | 地址 | 数据类型 | 描述 |
|---------|------|---------|------|
| 示例：DB1.DBD0 | DB1.DBD0 | Real | 运行状态 |
| 示例：DB1.DBD4 | DB1.DBD4 | Int | 产量计数 |
| 示例：DB1.DBW8 | DB1.DBW8 | Word | 故障代码 |

### 四、安全要求

1. **只读访问**：仅需读取数据，不涉及写入操作
2. **通讯频率**：建议1-5秒一次
3. **数据保护级别**：请设置为"允许来自远程对象 PUT/GET 访问"

### 五、回复要求

请贵司在**3个工作日内**确认：
1. S7协议是否已开放
2. 如需设置访问权限，请提供操作步骤或协助配置
3. 提供完整数据区点位表
4. 指定技术对接人

如有技术问题，请联系：
- 对接人：{姓名}
- 电话：{电话}
- 邮箱：{邮箱}

此致

敬礼！

## 使用说明

### 何时使用哪个模板

| 设备情况 | 推荐模板 |
|---------|---------|
| 设备有网口，未知协议 | 模板一（ModbusTCP通用版） |
| 西门子PLC设备 | 模板二（S7协议专用版） |
| 高端设备/进口设备 | 模板三（OPC UA版） |
| 老旧设备/仅串口 | 模板四（串口通讯版） |

### 填写要点

1. **设备信息**：从设备铭牌获取型号、厂家信息
2. **网络信息**：提前确认IP地址分配方案
3. **时间点**：明确采集哪些数据（运行状态、产量、报警等）
4. **时间要求**：给厂家3个工作日回复，预留缓冲时间
5. **跟进方式**：发函后3天主动电话跟进

### 常见问题

**Q: 厂家说没有协议怎么办？**
A: 询问是否有SCADA系统或上位机软件，可从那里提取数据。

**Q: 厂家要求收费怎么办？**
A: 确认是否包含在设备保修范围内；如超出，评估成本是否值得。

**Q: 点位表不完整怎么办？**
A: 至少要求提供运行状态和产量两个关键点，其他后续补充。
