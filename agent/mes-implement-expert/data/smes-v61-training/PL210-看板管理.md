# PL210 看板管理 — 鼎捷 MES V6.1 培训沉淀

> 来源：`raw/PL210_看板管理模块操作简报.pdf`（26 页，2026-08-23 学习）
> 定位：现场生产信息的**实时可视化看板**——生产/质量/设备/综合四类标准看板 + 自定义看板，集成**帆软/亿信** BI 报表。
> 对应 smes-621 数据字典：`08-andon-system-erp.md`（安灯/报表）。三厂小簧 7-28 大屏为看板应用场景。

## 一、模块概述

看板管理的目的：
- 传递现场生产信息、统一思想
- 杜绝现场管理漏洞（生产进度、质量现状管控）
- 绩效考核公平化、透明化
- 保证现场作业秩序、提升形象

两个二级模块：
1. **看板配置** — 系统参数 + 自定义报表设置（新增/修改看板）
2. **标准看板**（K01-K04 四类）+ 自定义看板

## 二、功能作业一览表

| 菜单权限编号 | 在线报工平台 | 功能名称 | 目的 |
|------|---------|---------|------|
| SS101_SYS_INFO | - | 系统参数 | 使用看板前设定帆软/亿信站台 URL |
| REPORT_BASIS | - | 自定义报表设置 | 新增看板，类型选择看板管理 |

## 三、作业说明（关键功能点）

### 3.1 看板配置
- **系统参数（SS101_SYS_INFO）**：设定帆软站台 URL / 亿信站台 URL。sMES 可集成帆软、亿信两种 BI
- **自定义报表设置（REPORT_BASIS）**：新增/修改看板；标准看板编号 K01~K04 类型管理看板，新增也选管理看板类型。**新增自定义看板后需添加群组权限才能在 H5 端显示**

### 3.2 帆软集成（V9/V10 URL 差异）
- **V9**：报表连结取 `formlet=` 后的路径；组合 URL = `[帆软站台URL] + '?formlet=' + [报表连结]`，例：`http://10.40.73.152:18301/digiwin/kanban?formlet=Standard%2Fzh_CH%2FsMES%2FQ%2FQ01.frm`
- **V10**：无法直接取路径需逻辑组装，资料夹顺序有调整：`http://10.40.73.152:18301/digiwin/kanban/view/form?formlet=Standard/sMES/zh_CN/K/K01.frm`
- 帆软 cpt 报表（外部报表连结直接填完整地址，V9 浏览器预览复制地址，V10 拼接 `http://IP:端口/digiwin/kanban/view/report?viewlet=...`）
- 权限配置 4 步：①系统参数配站台 URL → ②添加自定义报表（外部报表连结）→ ③添加报表权限（菜单权限 K01-K04 之一 + 在线报工平台权限=自定义报表编号）→ ④用户加入群组 → ⑤H5 查看

### 3.3 亿信集成
- 地址从亿信「数据分析→预览页面」复制（resid=...）；不进入登录页需拼接账密 `&id=admin&pw=admin`
- 权限配置同帆软 4 步

## 四、标准 vs 实测差异（自我批判）

| 功能点 | V6.1 标准说明 | 库内实测/现有资产 | 判定 |
|--------|--------------|------------------|:----:|
| K01-K04 标准看板 | 车间/质量/设备/综合四类管理看板 | 三厂小簧 7-28 沟通：大屏网线/人员分组（看板大屏部署）；但**报工未启用，看板数据源未跑通** | ⚠️ 待厂区验证（数据源依赖报工/稼动启用） |
| 帆软/亿信集成 | URL 拼接 + 自定义报表设置 | 未在库内验证集成配置；华纬大屏是否用帆软待核实 | ❓ 待确认（集成 BI 厂商未确认） |
| 群组权限 | 新增看板需群组权限 H5 显示 | H5-作业群组权限清单（smes-621 配套）含看板相关权限 | ✅ 已实测（权限清单有看板项） |
| 报表数据源 | 设备稼动/生产状况/品质 | 报工报表 7 视角可作看板数据源（按天/按设备/按人员） | ⚠️ 待厂区验证 |
