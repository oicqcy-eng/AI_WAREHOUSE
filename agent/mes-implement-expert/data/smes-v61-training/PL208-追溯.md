> 定位：**成品/物料追溯**——批次级与单件级（成品序列号）两条追溯线，覆盖**人机料法**，含跨生产断阶物料追溯机制。
> 对应 smes-621 数据字典：`09-core-ops-补录.md`（TBLWIPCONT_MATERIALLOT）、`01-wip-workorder.md`（TBLINVFGDINDETAIL）。

## 一、模块概述

两个二级模块：
1. **质量追溯管理** — 批次级质量追溯（QTR608）、成品序列号质量追溯（QTR607）、质量追溯自定义设置（SS117）
2. **H5-质量追溯** — 移动端追溯查询

**追溯范围**：人（人员）、机（设备）、料（物料）、法（作业站/工艺）。

**追溯核心概念**：
- **单件级（成品序列号追溯）**：产品入库/出库时记录每个成品序列号（SN），从序列号反查全程生产信息
- **批次级（批次质量追溯）**：按生产批追溯质量数据

## 三、作业说明（关键功能点）

### 3.1 成品序列号质量追溯（QTR607）
- 正向追溯：**产品**正向追溯——从产品序列号（`TBLINVFGDINDETAIL.LOTNO`）出发，追溯该产品生产全程：生产批→作业站→设备→人员→物料
- 追溯内容含生产参数、检验数据

### 3.2 批次级质量追溯（QTR608）
- 反向追溯：**物料**逆向追溯——从物料批号（`TBLWIPCONT_MATERIALLOT.MATERIALLOTNO`）出发，追溯该物料用于哪些生产批、哪些产品

### 3.3 跨生产断阶追溯（关键机制）
MES 与 ERP 之间物料批号传递存在断阶，靠接口衔接：
```
tblINVWIPInventory_SEMI.lotno（MES 半成品库存批号）
  → stockin.data.create 接口（入库）→ lot_no
  → issue.wo.item.process 接口（领料发料）→ tblOEMOMaterialState
  → 与 MES 生产批关联完成物料追溯
```
- `tblOEMOMaterialState` 是 MES←ERP 物料状态桥接表，物料批号经此跨系统衔接
- 追溯断阶的实际数据流需连库验证（09 补录 `TBLWIPCONT_MATERIALLOT` 实测）

### 3.4 质量追溯自定义设置（SS117）
- 两阶报表挂载：可自定义追溯报表（批次级）
- QTR608 批次级追溯支持自定义挂载

### 3.5 异常类型（追溯视角）
生产过程中记录的异常类型：异常下模、生产暂停、设备稼动故障、设备产线变更、机台检验异常
