# PL111 系统配置 — 鼎捷 MES V6.1 培训沉淀

> 来源：`raw/PL111_系统配置模块操作简报.pdf`（142 页，2026-08-24 学习）
> 定位：**系统初始化总纲**——企业上线 sMES 前依据实际业务把通用系统转化为满足特定企业需要的系统（参数/单位/特性/编码规则/ERP 对接/讯息配置/授权管理）。是使 sMES 系统**成为企业专属系统的基础**，也是所有功能作业得以运转的前提。
> 功能架构：`flows/PL111/PL111_系统配置模块操作简报_p010_2.png`（六个二级模块）
> ⚠️ 本模块是**上线前一次性配置**，一经设定不能随意更动（部分可后期调整，修改务必谨慎）。由 IT 单位或顾问执行。
> 关联：讯息配置=PL207 Andon 预警的消息体系基座；上料叫料参数=PL202 车间物料管控开关；移动端权限=PL104 生产任务中心 H5/手机报工前置；稼动状态参数=PL102 设备稼动。

## 一、模块概述

管理目的：在系统初次运行时一次性完成系统初始化，主要包括**参数设定、ERP 设定、讯息配置、设定查询、其他功能（在线用户/授权/移动端）**六大块。企业上线前的准备工作=系统初始化，是使 sMES 系统的基础；科学的系统配置是业务处理的重要前提。

六个二级模块（约 47 功能点）：
1. **参数设定**（7 大作业 21 功能点）— 系统参数/系统信息、SMTP 信息、密码规则、单位设置、特性设置、批号规则（含 IPQC/成品序号/包装箱号/条码序号）、条码打印×10
2. **ERP 配置及管理**（9）— ERP 集成设置、自动执行排程设定、ERP 单据还原、ERP 数据重新接收、ERP 重新发起、ERP 调度队列查找、报工单调账、入库转抛调整×3
3. **讯息配置**（8）— 网页公告栏、常用语、消息模板、消息模板发送设置、消息分类负责人（相关+主要）、消息标签、消息发送记录
4. **设定查询**（2）— 交易事件记录、配置错误记录
5. **其他功能**（3）— 在线用户管理、授权管理（一般/轻量/模块）、移动端权限配置

## 三、作业说明（关键功能点）

### 3.1 参数设定（核心）

- **系统参数/系统信息（SS101_SYS_INFO）**：本系统 120+ 参数，启停关系许多功能的运作及资料处理逻辑。**上线前必须了解参数的管理意义，一经设定不能随意变动**。参数分页签：系统信息 / SMTP / 密码原则（详见「四、关键系统参数」）
- **SMTP 信息**：维护邮箱地址，自动排程执行记录发送至管理 mailbox。7 必填栏位（寄件者别名/使用者编号/密码/服务器/SSL/Port/电子邮箱）+【测试寄送电子邮件】验证
- **密码原则（8 条规则）**：每隔 N 天换密码 / 禁止连续 N 次密码输错 / 至少 N 个字符 / 至少 N 个英文字母 / 至少 N 个阿拉伯数字 / 新旧密码需 N 个字符不同 / 密码不可与账号相同 / 密码同一字符可出现 N 次 / 密码不可出现下列字符串。⚠️ **使用者基本资料设定前完成**
- **单位设置（UNIT_BASIS）**：定义单位类别（长度/重量等，**不用事先建档，直接输入**）及转换比率。**最小单位转换率 = 1.000000**；一般单位转换（如工单单位 pcs→kg）函数固定用 `funUTPRDOPUnitConversion`。有整合 ERP 可 ERP 汇入
- **特性设置（ELEMENT_BASIS）**：sMES 系统弹性与延展性的关键，各功能页面【属性】来源。需【签核】才可被引用。
  - **特性类别**：Common(公用)/Equipment(设备)/Material(物料)/OP(作业站)/Process(流程)/Product(产品)/ENG(工程)/Inventory(仓库)/OP Attrib(作业站属性)/Recipe(设备参数资料)/QCItem Parameter(品管项目参数)
  - **数据类别**：Numeric(数值)/String(字符串)/Percent(百分比)/Date Time(时间)/Boolean(布尔值)
  - **转换方式**（String 时）：Not Change(不转换)/Upper Case(转大写)/Lower Case(转小写)
  - **有效性检查**：Not Limit(不限制)/Assign Vaild Value(指定有效数值，需维护有效数据)/Min-Max(最小/最大值)/Reference System Parameter(参考系统参数)
- **批号规则设定（SSD01/SSD07）**：定义编码原则（批号/IPQC 检验单编号/成品序号/SMT 板号/包装箱号/条码主序号）。default 表示系统预设可修改，输入后需**启用**。
  - **段别定义**：每段定义**资料来源**（如 MO 号码）+**数字撷取栏位**；序号类可选**长度及进位方式**。范例：2 段编号 = MO 号码 + 流水号
  - **进阶（SSD07）**：`标准`=生产批批号照预设标准序号规则生成；`依不同区段编码`=区段内工单按区段设置的批号序号规则生成（区段没设则取预设标准序号）
  - ⚠️ 批号/IPQC 等若干资料只能有一套编号规则；IPQC 编号规则对接 QMS 系统时用到
- **条码打印（SS61001-61010）**：人员/仓库/储位/不良原因/载具/设备/指令清单/ERP 单别/上下工原因/等待原因 10 类基础资料条码化，供扫码使用

### 3.2 ERP 配置及管理

- **ERP 集成设置（ERP_SETTING）**：**集成类型=使用中台整合接口**；ERP Web 服务网址（`http://xxx:port/IntegrationEntry?wsdl`）；使用者账号密码（ERP 提供）；营运中心代码+营运据点（T100 专属，基本信息同步时依此取出对应信息抛回 MES DB）。⚠️ 由 IT 执行，**一经设定不能随意更动**
- **自动执行排程设定（核心）**：
  - **任务管理**（手动 API 建立）：编号/名称/目标类别(API 接口)/目标编号/默认请求。⚠️ **JOBNO 及 JOBNAME 查 6.0 版 `TBLSCHAUTORUNJOB` 表**；输入 API 时需将 `fun` 拿掉（如 `funMESCallERPInventoryBasis` → `MESCallERPInventoryBasis`）；PARAMETER01/02/03 对应自动排程参数 1/2/3（群组 mail 名称/500/日期）
  - **调度管理**（自动运转时间）：编号/名称/目标编号/默认请求/循环方式=`Simple`(简单循环)/`Cron`(条件式循环)；可立即执行/启动暂停/执行纪录/删除
  - ⚠️ RunMsg 系统运行日志接收 H5 事件需额外设置 AP 主机资料（IP/PORT/Env 正式区 Production 测试区 Test）
  - **36 个自动排程服务**详见「五、自动排程服务」
- **ERP 单据还原（ERP_DOCUMENT_LOG）**：10 类别——①工单发料(ERP 发起仅查询) ②工单退料(ERP 发起仅查询) ③报工单(AutoRun) ④成品入库(H5/AutoRun) ⑤不良品入库(H5/AutoRun) ⑥外包出货(H5/AutoRun) ⑦外包回货(H5/AutoRun，有 sQMS 检验同步发起检验单还原) ⑧MES 发料(AutoRun) ⑨ERP 外包回货(ERP 发起仅查询) ⑩当站下线入库(H5/AutoRun)
- **ERP 数据重新接收（ERP_RE_TRANSACTION）**：与 ERP 资料同步的背景服务失败的部分重新发放同步
- **ERP 重新发起（SENDTOEAIQUEUELOG）**：仅**自动入库及倒扣料** 2 个行为；选数据→重新发起→显示入参出参
- **ERP 调度队列查找（SS119）**：查 sMES 发 ERP 的服务纪录及回传结果
- **报工单调账（ALTERREPORTDATA）**：修改机时/人时/数量。⚠️ **只针对未发起回 ERP 的报工单**（已抛转 ERP 的不可调）
- **入库转抛调整×3**：良品入库 / 当站下线 / 不良品入库-报废

### 3.3 设定查询

- **交易事件记录（ERP_TRANSACTION_LOG）**：查询 ERP 传入服务信息记录，可检视 **4 类 XML**（传入 XML/传出 XML/讯息 XML/例外讯息 XML）确认串入资料明细。记录含日期/时间/使用者/动作（增添/修改/删除/核准/打印）
- **配置错误记录（ERROR_LOG）**：查阅系统配置错误记录，可删除

### 3.4 讯息配置

- **网页公告栏（SYS_BULLETIN）**：建信息→【核准】→资料出现于首页
- **常用语（MSG_PHRASE）**：新增讯息/编辑模板开窗选片语，需【签核】被引用
- **消息模板（MSG_MODEL_BASIS）**：模板=发送规则载体。**驱动**（检核是否需要发送的时机）=`时间`/`工单下线`/`开立生产批`/`出站`/`设备稼动`/`模具下模`/`模具叫修`；驱动=时间时显示**循环模式**（指定时间一次/每星期几/每多长循环）。⚠️ 驱动=时间需**新增一支自动排程作业，工作编号=模板编号**（RunMsg）
- **消息模板发送设置（MSG_MODEL_SEND_BASIS）**：选模板编号→自动带出发送内容及触发条件→输安灯讯息发送配置栏位→添加触发条件→【签核】。⚠️ 发送设定完成后需**将发送编号回写到消息分类负责人**
- **消息分类负责人设置**：接收者分类（区域/区段/流程/作业站/设备/人员）+分类值+发送编号；明细添加人员+**执行时间（分钟整数）**。⚠️ ①维护后发送安灯时才能选到收件对象 ②执行时间必须整数分钟（多层级发送，见 PL207）③没设发送编号则所有模板发送可用；绑定后专用
- **消息标签（MSG_TYPE_BASIS）**：默认带出 4 个（设备/仓库/公告/质量）
- **消息发送记录（MSG_WATCH_HISTORY）**：查询发送情况（未发送/发送中/发送成功/已阅读/发送异常），异常可【重新发送】

### 3.5 其他功能

- **在线用户管理**：**方式一**（车间后台网页）—确认环境 IP/Port/正式区测试区→设定→在线用户列表（登入账号/计算机名/IP，H5Client 为 H5/空闲时间）→删除=强制登出；**方式二**（平台运维）—开启→在线人数→删除强制登出
- **授权管理**：
  - **标准授权**（授权档名 `iMESLicenses`）：各模块功能皆可使用；使用轻量化功能的用户数**同样扣除一般授权用户数**
  - **轻量授权**（授权档名 `LightLicenses`）：①手机报工模式 ②H5 端工位机模式功能 ③客户想用轻量化授权进 MES 看到更多功能要客制登入程式；使用轻量化功能的用户数**仅扣除轻量化授权用户数**
  - ⚠️ **轻量化授权 10 人时，第 11 位登录会把第 1 位登出**
  - **模块授权**：显示标准/轻量/模块授权相关资讯；轻量授权人数=0 表示无购买
- **移动端权限配置**：质检人员巡检需来回走动→移动 Android 手机/PDA 报工。配置路径：生产模型配置-人员配置-群组权限设置→选群组→**在线报工平台权限**→【添加】选权限。⚠️ **手机端权限包含在 PC 端同名权限中，是共用的**；手机端**首检/巡检**作业对应权限=**待检清单/检验作业**
