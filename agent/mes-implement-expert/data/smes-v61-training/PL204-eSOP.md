# PL204 eSOP — 鼎捷 MES V6.1 培训沉淀

> 来源：`raw/PL204_eSOP模块操作简报.pdf`（20 页，2026-08-24 学习）
> 定位：**标准作业程序（SOP）电子化展示模块**——把产品+作业站/工序维度的作业指导文件（PDF/视频/图片）上传系统，生产批进站后在工位机/作业站界面主动推送或手动查看，规范作业。
> 功能架构：`flows/PL204/PL204_eSOP模块操作简报_p005_2.png`（eSOP 设定 + eSOP 查看 两二级模块）

## 一、模块概述

eSOP = **S**tandard **O**perating **P**rocedure 电子化。价值：缩短新员工学习时间（降培训成本）、减少资源浪费（降生产成本）、提高生产稳定性（降失误）。

三个二级模块：
1. **eSOP 设定**（3 个）— 产品类别-序号收集、产品基本资料、批量导入
2. **eSOP 查看**（3 个）— 生产线序号收集、作业站序号收集、eSOP（三大工作平台手动查看）
3. （说明：产品类别-序号收集功能在 **PL203 序列号收集**模块介绍，eSOP 模块借用其设置判断哪些工位机/设备推送 eSOP）

## 三、作业说明（关键功能点）

### 3.1 eSOP 设定
- **产品类别-序号收集（SOP_PRD_TYPE）**：设定哪些工位机/设备**主动推送** eSOP 文件。⚠️ 注意（作业站区域类型决定）：
  - **离散型功能区** → 只能选**设备**（不能选工序），对应在**作业站序号收集**操作
  - **连续性生产线型区域** → 只能选**工序**（不能选设备），对应在**生产线序号收集**操作
  - 序号收集类型无论选哪项，都会显示 eSOP 文件
- **产品基本资料（SOP_PRD_BASIS）**：上传产品+作业站、产品+作业站+工序维度的 eSOP 文件。操作：产品基本资料界面 → 选产品 →【eSOP 设定】→【添加】→ 选作业站编号，如需工位级还需输入**工序、序号** → 选 eSOP 文件路径 →【确定】
  - ⚠️ 工序为空 = eSOP 维护在**作业站下**；维护工序维度需**提前建立工位基本资料**
  - 每种维度下可维护**多个** eSOP 文件；序号=同维度下 eSOP 显示顺序
  - ⚠️ **上传档案限制最大 10MB**
  - ⚠️ **系统读取 eSOP 标准存放路径：`DefaultSite\sMES_Service\eSOP`**（H5 端在此取用）
- **批量导入**：透过来源资料夹批次汇入 eSOP（用于大量产品/多版本维护）
  - 设定步骤：①准备符合定义的 eSOP 文件产品对应夹 ②MES 主机 AP Server 设定来源路径夹 ③设定自动执行排程定期更新/新增
  - **文件夹定义（以 `_` 区隔）**：第一层 `产品编号_产品版本` → 第二层 `作业站编号` → 第三层 `工序编号` → 第四层 `eSOP 档案名称`（命名：`产品编号_产品版本\作业站编号\工序\序号_ESOP档名称`，例：`6799-C101-R01\TQQ001\...`）
  - **支援格式：PDF、MP4、JPG、PNG**（非以上格式不新增/更新）
  - **自动排程设置**：工作名称「批量导入 eSOP 功能」，参数01=来源路径（例 `D:\Test\ESOP`），参数02=汇入处理模式（**预设 I**，I=新增/U=更新）

### 3.2 eSOP 查看
- **生产线序号收集（E01）**：生产批进站后系统主动推送**工序维度** eSOP 文件（工位机界面右侧整块显示，可放大缩小、多张切换）
  - 工位机设定：选生产线/作业站/工位/序号是否单笔确认；需**提前完成产品类别序号收集设定**才可选到工位
  - ⚠️ **序号单笔确认**：是=每刷入一笔序号自动确认前一笔；否=不自动确认
  - ⚠️ **生产批进站报工后**，在生产线序号收集才会出现此生产批，才能推送对应工序 eSOP
- **作业站序号收集（E08）**：生产批进站后系统主动推送**作业站维度** eSOP 文件（右侧整块显示，可放大缩小/切换）
  - 工位机设定：选区域/作业站/设备/序号是否单笔确认；需提前完成产品类别序号收集设定
  - ⚠️ 因产品类别中设定此设备序号收集类型为显示 eSOP，故右侧整块显示该作业站下 eSOP 文件
  - ⚠️ 生产批进站报工后才出现此生产批并推送
- **eSOP 查看（三大工作平台）**：生产线/作业站/作业区工作平台，生产批**任意状态**下作业人员均可**手动点击**查看作业站下 eSOP 文件
  - 点选生产批 → 泡泡按钮【eSOP】→ 进入查看界面；左侧=eSOP 文件列表（按**工序+序号**排序），右侧=具体文件可放大缩小

## 四、标准 vs 实测差异（自我批判）

| 功能点 | V6.1 标准说明 | 库内实测/现有资产 | 判定 |
|--------|--------------|------------------|:----:|
| eSOP 主档/明细 | 产品+作业站/工序维度 eSOP 设定 | 生产库实测有 `TBLESOPBASIS`/`TBLESOPDETAIL`（均 0 行）；`tblPRDeSOPBasis`（0）/`tblPRDeSOPBasisNew`（**10562 行**）/`tblPRDeSOP_File`（0）/`TBLPRDESOPLOG`（87） | ⚠️ 产品维度 eSOP 设定真实在用（1 万+记录），但主档表 0 行需核实表间分工 |
| eSOP 文件存储 | `DefaultSite\sMES_Service\eSOP` 标准路径 | 文件存放路径在客户服务器实际位置待核（共库服务器 192.168.200.18） | ❓ 待确认 |
| 主动推送（E01/E08） | 生产批进站后工位机/作业站序号收集推送 | 三厂/一厂/重庆是否启用 eSOP 主动推送待核（需序号收集 + 工位机环境） | ⚠️ 待厂区验证 |
| 批量导入 | 来源夹+排程自动汇入（PDF/MP4/JPG/PNG） | 是否配置「批量导入 eSOP」排程待核；`TBLPRDESOPLOG` 87 行可能是汇入记录 | ❓ 待核实 |
| 三大平台手动查看 | 任意状态可点【eSOP】查看 | H5 端工作平台是否开放 eSOP 入口待核 | ⚠️ 待厂区验证 |
