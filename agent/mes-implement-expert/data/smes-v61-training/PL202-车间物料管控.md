# PL202 车间物料管控 — 鼎捷 MES V6.1 培训沉淀

> 来源：`raw/PL202_车间物料管控模块操作简报.pdf`（49 页，2026-08-24 学习）
> 定位：**车间物料上下料/借还/叫料管控模块**——记录物料从发料、使用到退料的过程与用量，实时通知仓库补充，达到「不断料、不错料、不屯料」。
> 功能架构：`flows/PL202/PL202_车间物料管控模块操作简报_p006_3.png`（五个二级模块）
> ⚠️ 关联：《PL106_物料上下料操作简报》详细介绍工单物料管理与扣料调整（同批次投放，到位后沉淀）。

## 一、模块概述

物料管理是制造业最重要环节：**不断料**（保证现场供给）、**不错料**（要用/可用的料进来）、**不屯料**（适量适时进料）。

两套能力（由系统参数「系统上料叫料开关」切换）：
- **标准模块**：物料上下料基本功能——上料扣减工单库存、下料增加工单库存，为 ERP 库存提供数据
- **增值模块**（本手册核心）：在标准功能精细化基础上，新增**叫料/下料通知、借料索还、物料转移**等，实时把车间需求通知仓库，实现不断料

五个二级模块（18 功能点）：
1. **物料管理配置**（4）— 作业站基本资料(用料选项/派工自动叫料)、设备基本资料(线边仓)、物料基本资料、产品基本资料(BOM)
2. **工单物料管理**（3）— 工单用料清单(OE204)、工单领料现况(OE205)、工单用料调整
3. **物料管理**（10）— 上料、下料、部分下料、叫料、物料转移、借料、索还物料等（工作平台/工位机执行）
4. **扣料调整**（2）— 扣料调整作业、未抛转倒扣料调整作业
5. **库房看板管理**（2）— 叫料看板、下料看板

## 三、作业说明（关键功能点）

### 3.1 物料管理配置
- **作业站基本资料-用料选项**（增值模块开启后）：
  - **发料点（不需上料）**：此作业站无法执行上料操作
  - **设备/产线/作业站/工位（需上料）**：投料点类别=工单时，分别需在对应层级执行上料；⚠️ 对比标准功能多了「作业站」「工位」两个选项（实现作业站上料/工位上料）
- **系统上料叫料开关**：启用=开启物料管理增值模块；不启用=标准物料上下料功能
- **派工自动叫料**：启用后派工自动生成叫料信息。配置流程：①系统参数「派工作业自动叫料开关」启用 → ②作业站基本资料「派工自动叫料」=是 → ③设备基本资料设定**线边仓**（显示发料目的地）→ ④派工自动生成叫料 → ⑤叫料看板查看（要料日期=派工预计开始时间，发料目的地=设备线边仓）
  - ⚠️ **叫料数量 = 派工数量 × 物料标准用量 + 派工数量 × 损耗率**
- **物料类别**：建立物料基础档前提。添加后需【签核】进入已签核页签才可被引用；**属性设定条码格式**用于上料扫码
  - 默认值 `MATERIALNO{4}OTHER{1}MATERIALLOTNO{3}OTHER{1}QTY{0}`；`{}`前=固定关键名称、`{}`内=值长度（0=长度不确定，**只能一个 {0}**，两个及以上 0=设定异常）
  - 撷取关键字：MATERIALNO=物料编码、MATERIALLOTNO=物料批号、QTY=物料数量、OTHER=不相关内容（可多组）
  - 范例：输入 `M-01-P01-100` → 物料编号 M-01、物料批号 P01、数量 100
- **物料基本资料-重要字段**：
  - **计量方法**：标准用量在工单展算时按此展算用料需求；使用用量则不展算 ⚠️（大部分用料由 ERP 工单转入，故请选择使用用量）
  - 是否检查批号：目前 sMES 还未使用
  - **关键用料**：设为关键料者在 ERP 转入工单时才进入 sMES 用料资料
  - **保存期限**：启用则上料验证有效期=生产日期+保存期限，不满足提示过期
- **产品基本资料-BOM**：选产品 →【展开】→【BOM 表】→ 产品用料表；可维护物料/半成品，建工单自动带入物料需求
  - **投料点类别**：`工单`（对应作业站用料选项为发料点→不需上料出站扣减；为设备/产线/作业站/工位→先上料且上料库存充足才可进站）／`工单倒扣料`（用后结算，不需上料，出站记使用量定时抛转 ERP）／`在制品库`（目前没有使用）
  - **叫料模式**：`自动叫料`（派工自动叫料 + 进站报工检查库存<最低存量自动叫料）／`手动叫料`（仅物料管理中手动叫料）
  - **损耗率**：耗损率 10%、标准用量 1kg → 出站报工默认耗用量 = 1 + 1×10% = 1.1kg
  - **指定**：是=此物料不可使用替代物料；否=可使用替代物料
  - **工位编号**：默认 N/A；设定后只有在此工位才需使用此物料

### 3.2 物料管理（工作平台/工位机，7 个入口）
- **前置-系统参数**：启用「系统上料叫料开关」后工作平台/工位机才看到物料管理入口，标准上料/下料隐藏
- **物料管理界面**：①当前工单当前作业站物料需求清单（上料/叫料/库存信息）②当前作业站用料选项（如产线上料→库存转移到 LJ-ZPLINE1 产线）③色灯=上料库存 vs 最低存量比对（≥绿色 / <红色）④【叫料看板】【下料看板】直达库房看板
- **上料**：点【上料】→ 扫条码（物料类别设了条码规则自动识别）或手输物料批号/数量/生产日期 →【确定】
  - ⚠️ 物料管理开启后**上料不检测工单物料库存**，库存为 0 也可上料；扣减后工单库存可为**负库存**
  - 上料后增加用料选项对应上料点库存（产线上料→产线库存，工位上料→工位库存）
  - **倒扣料上料叫料开关**：启用→工单倒扣料可上料/叫料；不启用→不显示在物料管理界面
- **下料**：工单完工出站后物料有剩余，执行下料将库存从上料处转移回工单
- **部分下料**：下料作业数量管控弹性，使物料有更多被使用机会
- **叫料**：选物料输入手动叫料数量 →【叫料】→ 库房叫料看板查看
- **物料转移**：仅投料点类别=工单倒扣料可执行（需开启倒扣料上料叫料开关）；选转移目的地→确定
- **借料**：紧急用料向其他工单借料；点【+】查物料现况（按批号查询库存>0 的工单）→勾选待借工单→确定；⚠️ 被借工单物料库存必须 >0
- **索还物料**：被借工单需用物料时索回借出物料

### 3.3 扣料调整
- **扣料调整作业**：出站报工时物料使用量输入有误，调整生产批出站物料扣减数量
- **未抛转倒扣料调整作业**：工单物料=倒扣料、未抛转 ERP 前，调整物料耗用数量

### 3.4 库房看板管理
- **叫料看板**：选择区域查看叫料信息并确认。叫料三类：**手动叫料**／**派工自动叫料**（派工后自动按物料需求发起）／**进站自动提示叫料**
- **进站自动提示叫料**（两种设定方式：产品用料表按物料改叫料模式=自动提示叫料+设最低存量；或工单用料调整）：
  - 流程：点生产批【进站报工】→ 系统检查物料上料库存<最低存量 → 出现提示框 → 确定 → 输入自动叫料数量 → 继续检查下一物料 → 全部检查完验证所有需上料物料上料库存>0 → 有物料没上料则**进站失败、自动叫料也失败**；全部已上料则进站报工完成
  - ⚠️ **自动叫料成功条件**：(1) 物料上料库存<最低存量；(2) 进站报工成功（所有需上料物料上料库存>0）
  - **今日生产任务物料状态色灯**：红=至少一个物料没上料；黄=全部上料但至少一个库存<最低存量；绿=全部库存≥最低存量
  - 库房确认后现场叫料状态：叫料中→使用中
  - **叫料状态**：待上料（没上料且没叫料）／使用中（已上料且无未确认叫料）／叫料中（已叫料且库房未确认）
- **下料看板**：车间加工完成下料后，库房查看下料信息并反馈

### 3.5 本模块常用系统参数（7 个）
| 参数 | 说明 |
|------|------|
| 系统上料叫料开关 | 不启用=标准物料上下料；启用=物料管理增值模块 |
| 出站扣料多批次扣料规则 | 本次出站生产批有多个物料批次上料时，决定扣料顺序 |
| 出站扣料计数保留方法 | 出站物料使用量计算方式 |
| 物料扣料保留小数位数 | 物料扣料保留小数位数（如出站使用量） |
| 重工批扣料模式选择 | 重工批是否扣料 |
| 入库单由 ERP 执行倒扣料 | 倒扣料 xml 由 MES 产生还是 ERP 自行产生 |
| 派工自动叫料开关 | 本参数+作业站派工叫料设置+工单用料调整叫料模式 → 该作业站派工是否自动叫料 |
| 倒扣料上料叫料开关 | 物料管理界面是否显示倒扣料上料信息 |
