# smes-v61-training — 鼎捷 MES V6.1 官方培训沉淀

> **鼎捷 sMES V6.1 官方培训简报**的学习沉淀库。官方培训为**标准产品功能**，对应不同客户有实施差异，沉淀时以**自我批判/自我验证**视角记录「标准功能 vs 客户实测差异」。

> 学习进度：2026-08-23 第一批 5 模块（PL101/201/208/210/214）；2026-08-24 第二批 8 模块（PL111/102/103/104/202/204/205/207），已全部分析沉淀。用户后续会继续投放其余模块培训文件。

## ⚠️ 标准 vs 实测两体系分离（铁律）

- **本目录 = 「标准说明书」**：只记录鼎捷官方培训的功能点位/说明/描述，**不写**客户实例事实
- **smes-621/（数据字典）、smes-621-sql/（实测查询）、iiot/（数采）、u9-sql/（U9）= 「客户实况」**：只记录华纬实例解析/连库实测的事实，**不掺**培训内容
- 两体系**互不抄写**，仅靠每模块「标准 vs 实测差异」栏做**引用式对照**（✅已实测 ⚠️待厂区验证 ❓与实测不符，指向实测资产路径）
- 后续沉淀任何模块，**禁止把培训内容写入 smes-621/ 或 smes-621-sql/，禁止把实测事实写入本目录**；发现两边不一致 → 记差异栏，不改任何一边

## 沉淀文件结构（每模块一致）

1. **模块概述**：定位、目的、二级模块
2. **功能作业一览表**：菜单权限编号 ↔ 在线报工平台权限编号 ↔ 功能名称 ↔ 必要性 ↔ 目的（全点位收录）
3. **作业说明**：各功能的功能说明、重要字段、注意/操作要点
4. **标准 vs 实测差异**：自我批判栏——每条功能点对照「V6.1 标准说明」与「库内实测/现有资产」，标注判定
5. **关联资产**：smes-621 数据字典表、smes-621-sql 查询、iiot/u9、各厂区口径卡
6. **待验证/注意**：标准功能在华纬各厂是否启用、未确认的边界

## 差异判定图例

| 标记 | 含义 |
|------|------|
| ✅ 已实测 | 库内数据/现有资产/连库实测佐证该标准功能真实生效 |
| ⚠️ 待厂区验证 | 标准功能真实存在，但华纬各厂区是否启用需按厂核实 |
| ❓ 与实测不符/待确认 | 标准描述与库内实测存在出入，需进一步甄审 |
