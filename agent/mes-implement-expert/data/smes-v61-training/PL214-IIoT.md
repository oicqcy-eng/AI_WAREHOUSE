# PL214 IIoT — 鼎捷 MES V6.1 培训沉淀

> 来源：`raw/PL214_IIoT模块功能介绍.pdf`（22 页，2026-08-23 学习）
> 定位：sMES **接收 IIoT 平台转发数据**做功能应用的模块——设备计数器/产量回报、生产参数仪表盘、定时定量自动出站。
> ⚠️ **IIoT 平台 ≠ IIoT 模块**：IIoT 平台是**另一个产品**（设备数据采集/清洗/转发），sMES 的 IIoT 模块**只负责接收并应用**转发来的数据。
> 对应资产：`../iiot/`（重庆数采平台——鼎华智能 IIoT v2.2.6.0，InfluxDB 8086）。重庆数采 32 台（权威口径）。

## 一、模块概述

架构：设备 → **IIoT 平台**（采集/处理/清洗/转发）→ **sMES IIoT 模块**（功能应用）→ 实时了解生产状态、设备性能、制造情况（稼动状态/生产参数），部分手动操作转自动作业。

四个二级模块：
1. **集成设置**（2 个）— 集成站台设置、集成设备设置
2. **设备集成信息** — 集成设备的生产参数/自动出站设定
3. **自动排程** — 生产批现况更新、定时定量自动出站
4. **接口清单** — production.edc.process 等 IIoT 接口

## 三、作业说明（关键功能点）

### 3.1 集成设置
- **集成站台设置（ESI01）**：建请求所需站台（大多为 IIoT 平台）。⚠️ **预设站台必须勾选且只能一个**；站台信息可不准确（预留功能），填写内容咨询 IIoT 平台
- **集成设备设置（ESI03）**：**只有集成设备才可用 IIoT 模块相关接口**。三块设定：①集成设定(自动出站) ②生产参数(仪表板监控+范围界定) ③生产数据(⚠️ 功能废弃待移除)

### 3.2 设备计数器及产量回报
- **接口 production.edc.process**：IIoT 转发设备计数器及产量，MES 直接写产量或进行产量计算
- **自动排程-生产批现况更新**：定时更新生产批批量、累计进站量、累计出站量
- **自动排程-定时定量自动出站**：定时检查设备是否达设定出站量，执行手动通知/自动出站。⚠️ 基于生产批现况更新处理，**执行频率要低于生产批现况更新**

### 3.3 集成设备设置-自动出站逻辑（核心）
重要字段：
- **目前计数量**：可手动调整。⚠️ **计数器数量 ≠ 产量**！
- **计数器差异异常值**：传入计数量与目前计数器差异超过则忽略传入值；为 0 时不检核
- **定量出站**：设备累积产量达设定值，自动排程触发时才出站
- **自动出站保留数量**：出站后剩余数量 < 保留量时不自动出站，仅触发通知：
  - `-1` = 半自动出站（不自动出站，产量达值触发通知）
  - `0` = 全自动出站，预设自动保留数量为定量数
  - `>0` = 全自动出站，自动保留数量以此数值为准
- **完工预告分钟**：出站前预告
- **模具寿命扣抵方式**：一般出站扣抵=以出站数量计算；机联模次扣抵=以计数器跳动数量计算

### 3.4 接收设备参数
- **前置-采集资料库链接**（必填）：机连数据可存**另外的数据库服务器**。MSSQL 连接串 `Provider=sqloledb;Data Source=IP;Initial Catalog=DB;User Id=xx;Password=xx`；ORACLE `Provider=OraOleDB.Oracle;...`
- **采集数据项基础数据（ESI02）**：项目编号/名称/资料型态（数字/文字/日期时间）
- **生产参数设置（仪表板）**：
  - 仪表类型：无(隐藏)/压力表式(指针，须设合格警戒标准)/号志灯(三色灯，须设标准)
  - **5 门槛值**：合格下限 < 警戒下限 < 标准值 < 警戒上限 < 合格上限（标准值必填；合格上下限未填不能设压力表仪表盘）
  - **实际检核状态**：G=合格 / W=警告 / X=不合格。⚠️ 一般情况下不应手动维护此栏位
  - 实际合格下限等=最近一次检核 5 门槛实际值（可能来自产品参数设定）
- **自动排程-设备集成信息比对分析**：工作名称 `ESIDataCompareProcess`（参数1=汇整日期，默认当日；频率）。三件事：①同步采集资料项（比对集成库与 sMES 设定，不一致则设成一样）②补足历程档资料项信息（采集项目 01/02/03 顺序编号对应实际项目）③**匹配采集资料项对应生产批**（采集当时的生产批信息更新到历程，多笔时主生产批=Y；预设取最晚进站那笔；⚠️ 回传讯息已含生产批编号时只该笔）
- **采集信息历程查询（ESI06）**：设备编号/名称/建立日期/设备回传时间；项目编号/名称/数据类别(N 数字)/资料来源(P 生产参数)；实际值；批号/主生产批/工单/作业站/产品/批量/预计产量/订单等采集时生产批信息
- **H5 端展示**：⚠️ **目前只接收数字型参数**；是否检核开关在集成设备设定-进站参数检核维护

## 四、标准 vs 实测差异（自我批判）

| 功能点 | V6.1 标准说明 | 库内实测/现有资产 | 判定 |
|--------|--------------|------------------|:----:|
| IIoT 平台 vs 模块 | 平台=独立产品，模块只接收应用 | 重庆数采=鼎华智能 IIoT v2.2.6.0 独立系统，数采实时数据在 InfluxDB(8086) **不落 sMES**；**MES 与数采当前各自为政**（2026-08-14 探查） | ✅ 已实测（边界确认，集成未打通） |
| production.edc.process 计数器接口 | 计数器/产量回报 → MES 写产量 | 重庆数采是否已通过该接口写入 sMES 待核实；**重庆数采 32 台 ≠ 报工 86 台**（数采与报工是两套口径） | ⚠️ 待验证（接口接入状态未确认） |
| 自动出站（保留数量-1/0/>0） | 半自动/全自动/尾批出站逻辑 | 华纬报工为手动进出站为主（报工数据 ENDTIME 收口）；自动出站是否启用待核 | ⚠️ 待厂区验证 |
| 计数器≠产量 | 计数器跳动 vs 出站产量 | 报工口径产量=InputQty/OutputQty（出站），非计数器值 | ✅ 已实测（口径区分明确） |
| 生产参数仪表板 | 压力表/号志灯 + G/W/X 检核 | 重庆数采参数采集存在（数采资产库）；是否做 MES 端仪表板/GWX 检核待核实 | ⚠️ 待厂区验证 |
| 采集资料库链接 | 机连数据存独立数据库 | 重庆数采数据在 InfluxDB(8086)，非 MSSQL/ORACLE 采集库 | ❓ 待确认（标准为关系库，实际时序库，架构差异） |
