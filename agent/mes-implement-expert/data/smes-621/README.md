## 使用说明

- **检索表结构**：进入对应模块文件，顶部有表清单（含字段数），点表名跳转字段明细
- **主键**：每表节首以 `> 主键：...` 标注复合主键
- **字段标记**：√ 表示该列为 主键/业务主键/自增/允许空值
- **追溯**：01~08 主字典出自设计文档 20250313；**09、10~16 为连库实测补录**（`INFORMATION_SCHEMA.COLUMNS`，结构为生产库实测），无人工增补字段；10~16 表级说明为表名词根直译（仅辅助检索）
