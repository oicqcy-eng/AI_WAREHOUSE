| 字典有/生产无 | 1 | `tblemsacclog_adjustlife`（可能停用/改名） |

> 🔬 **2026-08-23 甄审复核（重要分层）**：设计文档 `SMES_621数据库设计文档20250313.html` 实际有 **773 张表定义**（771 在生产库），而主字典只是**按 8 业务模块挑选解析的 192 张**（约 25%）。因此「1281 生产有/字典无」并非单一缺口，细分为：
> - **580 张 = 设计文档有 / 主字典无** → **断连可查 HTML 原件结构**（`../smes-621/raw/`），不依赖主字典；其中业务核心表 285 张（WIP/PRD/OP/USR/OEM/INV/EQP/QC 前缀）
> - **701 张 = 设计文档也没有（真·生产独有）** → 断连原本无任何离线结构，只能连库验证；其中业务核心前缀 **320 张已批量补录全结构**（[../smes-621/10-wip-补录.md](../smes-621/10-wip-补录.md)~[16-usr-oem-补录.md](../smes-621/16-usr-oem-补录.md)，2026-08-23，3209 列），余约 384 张为平台/二次开发/备份

### 为什么 68 张表最关键

编制时点（08-21）的 22 个通用查询模板实际 `FROM/JOIN` 的表中，**68 张不在 192 字典** —— 即我们日常跑报表/排查依赖的核心表（`TBLWIPLOTBASIS`/`TBLWIPLOTLOG_REPORT`/`TBLWIPCONT_EQUIPMENT`/`TBLUSRUSERBASIS`/`TBLEQPEQUIPMENTBASIS`/`TBLOPBASIS`/`TBLWIPEQPQCLISTLOG` 等）结构此前**未入主字典**，断连即断。现已全部补录（查询清单现已扩至 25 个）。⚠️ 甄审复核（2026-08-23）：68 张中 66 张设计文档本就有（当时补录未先查 HTML 原件，直接连库实测——结构无误但路径可选更优），真·设计文档无的仅 2 张。

## 三、使用

1. **找表**：查本清单（grep CSV）确认表存在 → 查 [../smes-621/](../smes-621/README.md) 字典——192 表主字典（01~08）**或** 68 表补录（[09-core-ops-补录.md](../smes-621/09-core-ops-补录.md)）**或** 320 表批量补录（[10-wip-补录.md](../smes-621/10-wip-补录.md)~[16-usr-oem-补录.md](../smes-621/16-usr-oem-补录.md)）→ 都没有则**查 `../smes-621/raw/` 设计文档 HTML 原件**（580 张设计文档有/主字典无的表可 grep 表名锚点取结构）→ 仍无则按需连库验证
2. **断连期**：本清单 + 580 表离线结构（192 主字典 + 68 + 320 批量补录）+ `../smes-621/raw/` 原件 + [sMES核心链路-表结构与排障.md](sMES核心链路-表结构与排障.md)；仅真·生产独有余约 384 张平台/二次开发表无离线结构，断连只能靠已知 SQL 模板现场取数
3. **重跑刷新**（连库可用时）：
```sql
SELECT t.name AS 表名, SUM(p.rows) AS 估算行数
FROM sys.tables t
LEFT JOIN sys.partitions p ON t.object_id = p.object_id AND p.index_id IN (0,1)
GROUP BY t.name ORDER BY 表名;
```
4. **注意**：`BKT` 前缀为备份表（非业务依据）；`temp`/`bak`/`Test_*` 为临时/测试表
