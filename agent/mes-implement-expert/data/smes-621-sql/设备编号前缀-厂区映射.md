# 设备编号前缀 → 厂区映射（华纬 MES）

> **来源**：`delivery/projects/hw-spring-mes/input/devices/设备基础数据_20260812102955.xlsx`（752 台设备，2026-08-12 归档）
> **用途**：判定某设备/查询归属哪个厂区；与 smes-621-sql 厂区限定 SQL 的限定条件互相验证。
> **注意**：前缀**非唯一**（材料车间与二厂都用 CP/CQ），判定厂区时**结合「设备类别」列或管理群组**，勿仅凭前缀。三厂小簧编号以 `X` 开头为主，但仅凭 X 会漏 6 台非 X 前缀的桥式起重机，准确判定应以**「设备类别」= 华纬三厂（小簧）**为准。

> **补充（2026-08-14 重庆库实测；2026-08-15 复核更新）**：重庆为独立 sMES 服务器（172.16.64.11/sMES_Home_Prod，见 `config/db.local.json` `cq` profile）。重庆设备 **2026-08-15 库内实测 98 台**拆两条产线：`EQ-CQSPR-*` 弹簧线 **40 台**、`EQ-CQSTB-*` 稳定杆线 **58 台**（来源重庆库 `TBLEQPEQUIPMENTBASIS`，SQL 见 `delivery/projects/hw-spring-mes/input/c_q_mes/sql/重庆设备主数据口径-SQL.sql`）。早期记录「86 台/全为 CQSPR」已先后修正为 86→98 台（CQSPR 28→40）。
>
> **补充（2026-08-15 报工/点检厂区实测）**：报工活跃度按 8-14 共库实测——金晟 `JS-%` 504 条（**共库报工量最大**）、二厂 `F%` 122 条、一厂 `101-01-DH%` 27 条、材料车间/拉丝 CL/CZ 27 条、W 系（WV/WS/WP/WU 等点检工位类）约 257 条；**三厂小簧 `X%` 设备 8 月起无报工**（最后报工 2026-07-23，历史 30 条）——三厂报工当前未启用，SSMS 版暂不产出，如启用改用 `X%` 前缀。二厂判定详见上表 F 系注。
> **全量清单（2026-08-15 沉淀）**：设备/人员/工序主数据**全量快照**见 [`设备主数据清单.md`](设备主数据清单.md)/[人员主数据清单.md](人员主数据清单.md)/[工序作业站字典.md](工序作业站字典.md)（按厂区类别分节，判定以 `EQUIPMENTTYPE` 列=厂区类别为准，本映射表为前缀维度，两者互补验证）。
