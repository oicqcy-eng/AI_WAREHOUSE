# sMES 主数据画像总览（两库快照，2026-08-15）

> **背景**：用户 2026-08-15 决策——MES 只读连库存在**断连风险**（连不上后只能靠扔文件资料），故把低频变化的主数据**一次性全量沉淀**为离线清单，断连后仍可查设备→厂区归属、工号→姓名、工序码→工序名、产品→作业流程。
> **范围**：设备 / 人员 / 工序 / 部门 / 作业流程（当前版本+产品绑定）全量；**物料 3 万+ 不全量**（只抽编码规则/类型/单位口径，见 [物料口径](#二物料编码规则口径不全量)）。
> **与四类分层策略的关系**：本总览是对「② 主数据/口径只抽映射不存快照」的**用户决策例外**——主数据低频变化、体量可接受，故快照沉淀；流水（③）仍坚决不沉淀。

### 2.2 物料类型（PRODUCTTYPE）

## 三、重跑刷新方法（断连前可执行）

三类主数据快照 SQL 见 `tmp/md-snapshot-home.sql` / `tmp/md-snapshot-cq.sql`（会话临时区，**非仓库资产**，重跑时按下方直接执行即可）：

```bash
# 本部共库（设备/人员/工序 → CSV）
node agent/mes-implement-expert/tools/query-mes.js --profile home --out tmp/md-device-home.csv -f tmp/md-snapshot-home.sql
node agent/mes-implement-expert/tools/query-mes.js --profile home --out tmp/md-user-home.csv -q "SELECT USERNO 工号, ISNULL(USERNAME,'') 姓名, ISNULL(DEPARTMENTNO,'') 部门, ISNULL(CONVERT(CHAR(10),RESIGNATIONDATE,120),'') 离职日期, ISSUESTATE 状态 FROM TBLUSRUSERBASIS ORDER BY USERNO"
node agent/mes-implement-expert/tools/query-mes.js --profile home --out tmp/md-op-home.csv -q "SELECT OPNO 工序码, ISNULL(OPNAME,'') 工序名, ISNULL(OPSHORTNAME,'') 短名, ISNULL(OPTYPE,'') 类型, OPCLASS 类别 FROM TBLOPBASIS ORDER BY OPNO"

# 重庆独立库（同上，--profile cq；设备快照无 C_factoryno 列）
```

物料口径 SQL（两库同款，`--profile home|cq`）：`SELECT LEFT(PRODUCTNO,3) 前缀, COUNT(*) 数量 FROM TBLPRDPRODUCTBASIS GROUP BY LEFT(PRODUCTNO,3) ORDER BY 数量 DESC` 及 PRODUCTTYPE / UNITNO 分布。

**二轮沉淀（部门/流程/产品绑定/区域）导出 SQL**（两库同款，注意 `--limit` 防截断；`--out` 只导出显示的 `--limit` 行数）：

```sql
-- 部门
SELECT DEPARTMENTNO, ISNULL(DEPARTMENTNAME,'') 部门名, ISNULL(ERPNO,'') ERP号, ISSUESTATE 状态 FROM TBLUSRDEPARTMENTBASIS ORDER BY DEPARTMENTNO;
-- 单位
SELECT UNITNO, ISNULL(UNITNAME2,'') 单位名, ISNULL(UNITTYPE,'') 类型, SYSTEMUNIT FROM TBLSYSUNITBASIS ORDER BY UNITNO;
-- 作业流程主档（当前版本）
SELECT PROCESSNO, PSNO, ISNULL(PROCESSTYPE,'') 流程类型, ISNULL(ProcessName,'') 流程名, PROCESSVERSION 版本 FROM TBLPRSPROCESSBASIS WHERE CURVERSION=1 ORDER BY PSNO, PROCESSNO;
-- 产品→流程绑定（默认流程）
SELECT PRODUCTNO, PSNO, PSORDER, PROCESSNO FROM TBLPRDPRODUCTPROCESS WHERE DEFAULTPROCESS=1 ORDER BY PRODUCTNO;
-- 工序→区域
SELECT OPNO, AREANO, DEFAULTAREA 预设 FROM TBLOPAREA ORDER BY OPNO, AREANO;
```

```bash
node agent/mes-implement-expert/tools/query-mes.js --profile home -q "<上述SQL>" --out tmp/md2-xxx.csv --limit 6000
```

> **快照 CSV → md 清单**：`tmp/md-gen.js`（一类）与 `tmp/md-gen2.js`（二轮，部门/流程/绑定/区域/单位解码）为会话临时脚本；生成后核对分节计数与库内 COUNT 一致再覆盖对应 md，并更新本文档规模表。
