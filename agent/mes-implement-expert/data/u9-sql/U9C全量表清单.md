## 三、使用

1. **找表**：查本清单（grep CSV）确认表存在 → 进 [U9C数据库字典-基础.md](U9C数据库字典-基础.md) 看已沉淀结构 → 若未沉淀，连库跑 `INFORMATION_SCHEMA.COLUMNS` 按需验证
2. **断连期**：本清单（表名/模块/行数估算）+ 链路手册（对接逻辑）足以离线推演；确需字段级结构时请 DBA 提供该表快照
3. **重跑刷新**（连库可用时）：
```sql
SELECT t.name AS 表名,
       LEFT(t.name, CHARINDEX('_', t.name + '_') - 1) AS 模块,
       SUM(p.rows) AS 估算行数
FROM sys.tables t
LEFT JOIN sys.partitions p ON t.object_id = p.object_id AND p.index_id IN (0,1)
GROUP BY t.name ORDER BY 模块, 表名;
```
4. **注意**：`cs`/`temp`/`bak`/`duplicate` 等前缀为**客户化/临时/备份**表，非用友标准业务表，勿当主数据依据
