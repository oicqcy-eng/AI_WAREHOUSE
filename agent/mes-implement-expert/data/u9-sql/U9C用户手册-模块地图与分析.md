## 一、手册概貌

手册是华纬 U9 数智化项目的**系统操作培训资料**，按「目录 → 整体流程（HW-XX-NN 编号）→ 业务关键词解释 → 业务方案实现」四段式组织。每页为 U9C 界面截图，页面右下角含流程编号与责任部门。

覆盖 **14 个模块**：销售(SD)、工程数据(BOM)、需求计划(MRP)、采购(PM)、生产(MM)、委外/河南华纬、库存(INV)、票据(NM)、应收(AR)、应付(AP)、现金银行(CM)、固定资产(FA)、成本(CA)、总账(GL)。

涉及组织：华纬集团、华纬科技股份有限公司、河南华纬（委外）、河南销售部、浙江物流部、实验室。

## 三、与 MES 对接相关的关键流程（重点）

### 3.1 采购收货检验及不合格处理（HW-PM-07）→ esb_iqc_receipt_outbox

手册流程节点（p145）：
1. 采购员收到送货通知，通知仓库收料
2. 仓管员根据采购员提供的订单信息办理**收货**并通知品质质检（U9C 收货单）
3. 品质部检验员根据收货单做**质检单**并执行检验操作
4. 检验是否通过？
   - 不合格 → 根据检验结果发起会审，与供应商协商处理方案
   - 合格 → 检验员将检验结果填入质检单，并告知仓库检验结果
5. 是否接收？
   - 接收 → 办理实物入库，审核采购收货单（或要求供应商送货单上录华纬采购订单号）
   - 拒收 → 知会采购员拒收明细
6. 结束 → 进入采购发票立账流程

> **与 MES 的对接点**：U9C 收货单产生后，通过 `esb_iqc_receipt_outbox` 出站队列同步到 sMES 做 IQC 来料检。MES 端只执行检验判定，不人工触发取数（详见 [U9C数据库字典-基础.md](U9C数据库字典-基础.md) 2.1 节）。

### 3.2 生产领料（HW-MM-01）→ ESB_IssueWoItem_Queue

手册流程节点：计划员根据周/日生产计划下达发料指令（承接生产订单下达流程）→ 仓库执行生产领料。

> **对接点**：U9 工单领料通过 `ESB_IssueWoItem_Queue` 同步到 MES，供工单扫码上料校验（见 [U9_ERP发料查询-SQL.sql](U9_ERP发料查询-SQL.sql)）。

### 3.3 生产完工检验（HW-MM-06）+ 完工入库（HW-MM-07）

手册流程节点（p187-188）：
- 生产完工检验：统计各生产工单产量数据 → 通知检验员进行检验 → 检验员告知统计员检验结果，由统计员通知车间执行
- 生产完工入库：车间包装组统计各车间完工合格产量数据 → 仓管员办理成品入库

> **对接点**：MES 完工申报/报工数据最终在 U9C 侧形成完工申报单（`101WS.24*`）、成品入库单（`101RK24*`）。排障时可通过 U9C 侧单据反查 MES 报工是否同步到位。

### 3.4 生产订单下达（HW-MRP-03）→ esb_mes_wo_create

MRP 运算释放生产订单后，U9C 工单同步到 MES 由 `esb_mes_wo_create`（工单同步状态表）记录（11 列，详见 [U9C数据库字典-基础.md](U9C数据库字典-基础.md) 2.3 节）。

### 3.5 工程数据来源：PLM → U9C

料品档案/BOM/工艺路线/定额工时均由**研发中心在 PLM 系统发布至 U9C**（BOM-01~04 均如此）。理解这一点可避免排障时在 U9C 内找不到主数据源头——源头在 PLM。

> - 工单：`MO`+组织码（101 华纬科技 / 106 河南华纬 / 107 重庆）+ 8 位日期 + 流水
> - 收货：`RCV`+组织码+日期+流水
> 手册中的 `101PO/101LL/101WS/101RK` 前缀需在对应表上实测确认后再用于 SQL。

## 五、沉淀结论与使用提示

1. **手册价值**：提供了华纬 U9C 的完整模块/流程编号地图，尤其是采购收货检验（→IQC）、生产领料（→发料）、完工入库、委外协同（河南华纬）四条与 MES 对接的链路语义。排障时可借流程编号快速定位业务环节归属。
2. **数据谨慎**：手册为 2024 年培训操作截图，所有单号/料品/客户均为示例，不能作为生产库过滤条件；生产取数口径一律以连库实测为准。
3. **仓库/组织命名**已实测确认，可在查询时作为仓库过滤条件（如 `1012500` 委外加工仓、`1012800` 重庆三方仓）。
4. **财务模块**（NM/AR/AP/CM/FA/CA/GL）与 MES 无直接对接，仅登记备用，未做流程细节沉淀。
