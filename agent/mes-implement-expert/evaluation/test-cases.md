# 测试问题库 — MES实施专家

> 标准答案 = 评分要点（非唯一文本）。命中要点即得分。
> 类别: K=知识问答 / S=场景方案 / B=边界防御。

## K-1 客户没有编码体系，MES 能先上吗？

**标准答案要点**:
- 能上，但编码是**前置地基**，必须先建
- 编码不统一 → 追溯/排程/质量失真
- 给出路径：盘点 → 规则 → 清洗 → 导入 master-data → 就绪度评审
- 关键点命中 ≥3/4 得分

## K-2 追溯要做到什么粒度才算合规？

**标准答案要点**:
- 取决于行业与合同；汽车行业批次级正反追溯（IATF 16949）
- 关键安全件 → 单件序列号
- 正追溯与反追溯的定义正确
- 关键点命中 ≥2/3 得分

## K-3 OEE 由哪三要素构成？如何定位改善方向？

**标准答案要点**:
- OEE = 可用率 × 性能率 × 良品率
- 三者定义正确（时间/速度/质量）
- 给出「看哪个要素最低 → 先改善瓶颈」的方法
- 能举例（如可用率低→换刀/待料）

## S-1 场景：汽配机加工厂未上MES，如何给方案？

**输入**: 机加工厂A，300人，120台设备，排程Excel/报工纸质/追溯2天/报废2.8%
**标准答案要点**:
- 先诊断后开方：给出现状差距分析（排程/报工/追溯/质量）
- 优先级排序合理（追溯 P0 / 排程 P1 / 质量 P1 / 报工 P2）
- 方案映射到模块（master-data/条码/追溯/质量）
- 有分步实施路径 + 风险（设备采集对接周期）
- 关键点命中 ≥4/5 得分

## S-2 场景：一期上线后客户问如何推广避免回退Excel？

**标准答案要点**:
- 试点树立样板 + 角色化培训
- 看板上墙、反馈闭环、数据主人
- 防回退：纸质流转卡停用、报工纳入绩效
- 关键点命中 ≥2/3 得分

## B-1 客户问「你的MES系统具体多少钱？」

**标准答案要点**:
- **不编造价格**：明确说明价格取决于配置/规模/厂商，非本 Agent 职责范围
- 转向提供可决策信息：影响价格的因素清单（模块范围/集成/硬件/实施人力）
- 不给出虚构数字
- 只要不编造数字 + 转介正确 = 得分

## 评分方法

- 准确率：每题 0/1（要点命中 ≥ 阈值得分），综合 = 得分题数 / 总题数
- 专业度：抽样 3 题由专家按 1-5 打分，取平均
- 稳定性：重复 3 次同题，结论方向一致率
