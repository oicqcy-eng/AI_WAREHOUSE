## [K-301] 汽配机加工厂追溯上线案例（骨架）

**场景**: 300人汽配机加工厂，未上MES，质量追溯需2天，客户要求批次追溯。

**方案要点**:
1. 编码体系先行（物料/工序/批次统一） → `base/master-data/`
2. 条码批次化 + 关键工序采集 → `base/barcode/` + `manufacturing/traceability/`
3. 正反追溯报表 → `manufacturing/traceability/`
4. SPC 作为二期（关键线试点） → `manufacturing/quality/`

**结果（示例指标）**:
- 追溯时长: 2天 → < 30分钟（正追溯）
- 数据及时率: 纸质滞后1天 → 实时采集

**可复用经验**:
- 编码就绪度决定上线速度（P0 优先）
- 一线报工阻力大 → 减少录入项 + 条码扫码替代手输
- 追溯报表要按「问题导向」设计，而非全字段堆砌

## [K-302] U9 ERP 发料接口缺条码字段 → MES 扫码上料校验受阻（跨系统取数链）

**场景**: 集团内部调拨物料条码在新组织不可用，MES 工单扫码上料检验无法使用（重庆诸暨调拨 / 一厂南京调拨同源）。

**方案要点**:
1. MES 从 U9 拉发料数据链路: `ESB_IssueWoItem_Queue`（发料队列）→ 关联领料单 `MO_MOPickList` → 校验工单已在 MES `TBLOEMOBASIS`（见 `data/u9-sql/`）
2. 上料校验需物料**条码**，但 U9 领料表与发料队列**均无条码字段** → U9 侧增字段/提供其他接口方案评估不可行
3. 正确解法方向: 评估 U9 其他数据源（如调拨单据/入库记录）是否带条码，或 MES 侧对无条码物料走替代路径

**结果**:
- 已定论: U9 领料链路无条码字段，该方案不可行（2026-07-06）
- 转等 U9 新方案（郑少青组织会议重新评估，2026-08-10）

**可复用经验**:
- **跨系统取数前先核对数据模型**: MES 需要的字段（条码/批次）是否在对方接口存在，避免接口开发完发现缺字段
- 发料/领料类接口常只带物料编码+数量，条码属于库存执行层数据，需找对单据类型
- 集团调拨条码问题跨项目同源（重庆诸暨 + 一厂南京），归一个根因跟踪
