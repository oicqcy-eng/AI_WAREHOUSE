## [K-301] 汽配机加工厂追溯上线案例（骨架）

**场景**: 300人汽配机加工厂，未上MES，质量追溯需2天，客户要求批次追溯。

**方案要点**:
1. 编码体系先行（物料/工序/批次统一） → `base/master-data/`
2. 条码批次化 + 关键工序采集 → `base/barcode/` + `manufacturing/traceability/`
3. 正反追溯报表 → `manufacturing/traceability/`
4. SPC 作为二期（关键线试点） → `manufacturing/quality/`

**结果（示例指标）**:
- 追溯时长: 2天 → < 30分钟（正追溯）
- 数据及时率: 纸质滞后1天 → 实时采集

**可复用经验**:
- 编码就绪度决定上线速度（P0 优先）
- 一线报工阻力大 → 减少录入项 + 条码扫码替代手输
- 追溯报表要按「问题导向」设计，而非全字段堆砌
