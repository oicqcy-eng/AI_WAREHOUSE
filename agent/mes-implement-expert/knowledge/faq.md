# FAQ — MES实施专家高频问题

> 用于 Agent 快速检索标准答案，减少重复推理。
> 每条含：问题 / 结论 / 依据 / 来源ID。

## [K-101] 客户没有编码体系，MES 能先上吗？

**结论**: 能，但**必须先建编码体系**，且编码是 MES 上线的前置地基（P0）。

**依据**:
- 编码不统一 → 物料/工序/批次无法关联 → 追溯、排程、质量全部失真
- 编码是 `base/master-data/` 的核心职责，其余模块依赖它

**建议路径**:
1. 盘点现有编码（ERP/纸质/Excel 中的物料、客户、供应商编码）
2. 制定编码规则（分类+流水，长度固定，含版本管理）
3. 数据清洗后导入 master-data
4. 上线 MES 前完成基础资料就绪度评审

## [K-102] 追溯要做到什么粒度才算合规？

**结论**: 取决于客户行业与客户合同要求。汽车行业一般要求 **批次级正反追溯**（IATF 16949），
关键安全件可能要求 **单件级（序列号）**。

**依据**: IATF 16949 追溯要求；客户合同质量协议。

**建议**:
- 正追溯：成品 → 关键物料批次/工序/设备/人员
- 反追溯：问题批次 → 影响成品范围
- 关键安全件：单件序列号 + 全工序记录
