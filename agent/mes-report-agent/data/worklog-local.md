# 本地化工作日志规范（2026-08-09 定版）

> **定位**: 原始工作日志与任务池的**权威数据源已从飞书多维表迁移到本地**（`data/worklog/`）。
> **原因**: 日志只在电脑操作、只给用户自用、汇报出文件即可；飞书 API 的网络延迟/不稳定/token 摩擦大于其协作价值。
> **速查**: 操作命令见 `data/worklog/README.md`。

## 1. 与飞书表的历史映射

| 飞书多维表 | 本地文件 |
|-----------|---------|
| 表1 原始工作日志 | `worklog/logs/YYYY-MM.json`（按月归档，跨项目全量流水） |
| 表2 任务问题归集池 | `worklog/task-pool.json`（全量单文件，任务跨月跟踪） |

**字段名不变**（中文字段名，与飞书一致），仅日期从毫秒时间戳改为 `YYYY-MM-DD` 字符串。

**迁移**：2026-08-09 一次性从副本表迁出 **291 日志 + 40 任务**（脚本 `tmp/migrate-feishu-to-local.js`）。飞书副本表保留为历史只读归档，**不再更新**。

## 2. 字段口径（沿用 report-bitable-spec.md §1/§2）

**日志记录**（必填 5 + 可选 5）：
`记录日期`(YYYY-MM-DD) · `所属项目` · `工作内容` · `结果类型` · `是否形成任务` / `业务模块` · `项目阶段` · `责任人` · `协作人` · `交付产出`

**任务记录**（必填 4 + 可选 9）：
`归集标题` · `对应项目` · `问题来源` · `优先级` / `发现日期` · `计划完成日期` · `实际闭环日期` · `任务状态` · `进度百分比` · `闭环判定标准` · `周报归集分类` · `协调资源需求` · `卡点&问题描述`

**选项枚举**（与飞书表完全一致）：
- 所属项目 7 项：三厂小簧sMES / 一厂大簧sMES / 二厂大簧sMES / 重庆sMES项目 / 实验室Lims项目 / 无锡泽根sMES项目 / 华纬其它项目
- 结果类型 8 项：问题关闭 / 方案确认 / 配置完成 / 培训完成 / 数据完成 / 上线验证 / 风险暴露 / 需求确认
- 优先级：P1/P2/P3/P4 · 任务状态：待启动/进行中/暂缓/已闭环 · 周报归集分类：本周完成/本周推进/重点问题/下周计划/长期跟踪
- 问题来源：现场反馈/系统异常/用户需求/会议决策/领导要求/审厂要求
- 业务模块 10 项、项目阶段 6 项：见 spec §1.1

## 3. 缺省值策略（沿用 spec §4.4）

用户口述/纪要未明确字段时取最低档：

| 字段 | 默认 |
|------|------|
| 结果类型 | `需求确认` |
| 优先级 | `P4` |
| 项目阶段 | `需求调研` |
| 任务状态 | `待启动` |
| 是否形成任务 | `否` |
| 业务模块 | `系统管理` |
| 所属项目 | 上下文推断；推断不了询问 |
| 记录日期 | 处理当天 |

## 4. 任务池准入规则（沿用 spec §4.2）

**进 task-pool**：停线风险 / 跨部门协调 / 系统BUG / 需求变更 / 领导关注 / 审厂要求
**只记日志**：普通会议 / 日常测试 / 简单配置 / 常规培训

## 5. 操作规范

| 场景 | 操作 |
|------|------|
| **打开录入页**（日常直接录入） | **双击 `start-worklog.bat`** → 浏览器自动打开 → 下拉选择/填写 → 保存 |
| 追加日志 | `node agent/mes-report-agent/tools/worklog-append.js log '<json>'` |
| 追加任务 | `node agent/mes-report-agent/tools/worklog-append.js task '<json>'` |
| 提取区间数据（周报/月报素材） | `node agent/mes-report-agent/tools/export-range.js <起> <止>` |
| 汇报 docx | `node agent/mes-report-agent/tools/md-to-docx.js <输出目录>` |
| **生成仪表盘** | `node agent/mes-report-agent/tools/generate-dashboard.js [输出路径]` |
| **导出 Excel**（发人/存档） | `node agent/mes-report-agent/tools/export-excel.js log\|task\|all [--project=X] [--month=YYYY-MM] [--out=路径]` |

**追加时的纪律**：
- 日志按 `记录日期` 的月份自动写入对应 `logs/YYYY-MM.json`；任务追加到 `task-pool.json`
- 追加前**先读对应文件**确认不重复（同一件事不重复入库）
- 修改记录：录入页【编辑】或 CLI `update-log/update-task`（按 `_id` 覆盖）；数据无稳定主键时用日期+内容定位
- 删除记录：直接 Edit 对应 json（保留合理的修订留痕，见 always-settle-knowledge 原则）
- **数据源是本地**：生成汇报前用 export-range.js 取数，不再调飞书 API

## 6. 汇报链路（不变）

export-range.js 提取区间日志+任务池 → Claude 按 `report-bitable-spec.md` §9 规范组织 md → md-to-docx.js 生成 docx（微软雅黑 8pt 表格、无来源信息、去总监字眼）。

## 7. 仪表盘（HTML 可视化，替代飞书仪表盘）

**工具**：`tools/generate-dashboard.js`，从本地 worklog 生成**自包含 HTML** 仪表盘（ECharts CDN 在线加载，浏览器打开即可）。

**默认输出**：`delivery/projects/hw-spring-mes/output/dashboard.html`（可传第 2 参数指定路径）。

**图表模块**（覆盖飞书仪表盘 §3 四类 + 增强）：
| 模块 | 图表 |
|------|------|
| ① 各项目健康度 | 分组柱状图（总任务/进行中/已闭环） |
| ② 优先级风险分布 | 环形图（P1/P2/P3/P4 未闭环）+ P1 高红预警横幅 |
| ③ 业务模块工作分布 | 横向条形图（日志业务模块统计） |
| ④ 月度日志趋势 | 折线面积图（跨月工作量节奏） |
| ⑤ 项目×任务状态 | 堆叠柱状图 |
| ⑥ 本周重点待协调 | 卡片列表（协调资源需求非空项） |
| ⑦ 近 7 天到期 | 任务清单（按计划完成日期） |

**用法**：每次数据更新（追加日志/任务）后重跑一次即可刷新；静态快照、本地生成毫秒级、可截图可全屏。

## 8. 录入页（替代飞书"打开直接录入"）

**启动**：双击仓库根 `start-worklog.bat` → 自动启动本地服务 + 打开浏览器录入页（http://localhost:8787）→ 关窗口即停止。

**组成**：
- `tools/worklog-server.js` — 本地 HTTP 服务（GET/POST，读写 worklog/，复用 worklog-append.js 的写入逻辑）
- `tools/worklog-ui.html` — 录入页（日志/任务双 tab，下拉选项来自 `/api/options`，保存后右侧实时显示最近记录与今日统计）
- `start-worklog.bat` — 一键启动脚本

**能力**：日志（项目/模块/阶段/结果类型/是否形成任务/责任人/协作人/交付产出 + 工作内容）与任务（标题/项目/来源/优先级/状态/发现/计划/实际闭环/进度/周报分类/协调资源/卡点）均可**录入**，必填校验 + 缺省值补齐与 CLI 完全一致。

**编辑**（2026-08-10 新增）：右侧最近记录每条带【编辑】按钮 → 点击加载到表单（顶部出现黄色横幅）→ 改完点「保存修改」按 `_id` **覆盖原记录**；点「取消编辑」放弃。改日期会跨月自动移动归档。覆盖后数据源即更新，周报/月报/仪表盘重新生成即反映修正。

**附件**（2026-08-10 新增）：日志/任务记录可带 `附件` 字段（可选），文件放 `worklog/attachments/` 下，录入页表单填文件名即可，最近记录会显示 📎 图标点击直接打开原始文档（如聊天记录/截图/表格）。Excel 导出时附件列一并带出。

**注意**：服务进程存在期间 worklog 文件由它管理；对话框/CLI 追加与录入页追加**共用同一数据源**（worklog/），实时可见，无同步问题。端口 8787 可被 `WORKLOG_PORT` 环境变量覆盖。

## 9. Excel 导出（发人/存档）

**工具**：`tools/export-excel.js`，把本地 worklog 导出为 `.xlsx`，随时可发给别人或 WPS 打开。依赖 `xlsx` 库（`tmp/node_modules`，运行时需 `NODE_PATH=/d/AI_WAREHOUSE/tmp/node_modules` 或从 `tmp/` 目录运行）。

**命令**：
- `node export-excel.js log` → `原始工作日志.xlsx`（全部日志）
- `node export-excel.js task` → `任务问题归集池.xlsx`（全部任务）
- `node export-excel.js all` → `工作记录_全量.xlsx`（两个 sheet 一个文件）
- 筛选：`--project=实验室Lims项目 --month=2026-08 --out=自定义路径.xlsx`

**默认输出**：`delivery/projects/hw-spring-mes/output/`。
