# 日常工作数据输入窗口

> **用途**：除了在对话框里口头说工作内容，还可以把**会议纪要 / 事项纪要**（word、txt、md、截图等）直接扔进这个文件夹。Claude 会读取并整理归纳进飞书多维表格「原始工作日志」（表1），需进任务池的同步建到「任务问题归集池」（表2）。

## 怎么用

1. 把会议纪要 / 事项纪要文件**复制**到这个文件夹（原文件保留在别处）
2. 在对话框说一声「**处理输入窗口**」（或类似的话）
3. Claude 会：
   - 读取文件夹里所有新增文件，提取工作内容
   - 按规范归类（所属项目/业务模块/项目阶段/结果类型，缺省取最低档）
   - 写入飞书「原始工作日志」，需进任务池的建「任务问题归集池」
   - 汇报：写了哪几条、归到哪个项目、建了几条任务
4. 处理完成后，纪要文件可移走或删除，保持文件夹**接近清空**

## 规则

- **只进不出**：纪要放这里只用于被读取，不会自动入库原始文件
- **缺省取最低档**：字段没提的默认最低档（结果类型=需求确认、优先级=P4、任务状态=待启动、是否形成任务=否）
- **所属项目**：从纪要内容推断，推断不了会询问
- **敏感材料不入库**：本文件夹的纪要文件被 `.gitignore` 忽略，不会提交进 git
- **日期**：纪要里写的日期优先；没写默认处理当天

## 支持的文件

- 文本类：`.md` `.txt`
- 文档类：`.docx` `.doc`
- 表格类：`.xlsx` `.xls`（有工作记录/事项清单的）
- 图片：截图（可读文字内容）
- 录音转写：直接贴文字或转写稿

> 规范细则见 `agent/mes-report-agent/data/report-bitable-spec.md`
