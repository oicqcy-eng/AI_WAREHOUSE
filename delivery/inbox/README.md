# inbox — 统一收件箱

> 所有新到的客户资料/素材**先进这里**，再按规则归类。**保持接近清空**。

## 用途

- 客户发来的需求文档、Excel、截图、录音转写等，先落在这里
- 未决定归属的素材暂存处

## 归类规则

| 资料类型 | 归到 |
|----------|------|
| 具体项目的需求/数据 | `delivery/projects/<项目>/input/requirements` 或 `sql` 等 |
| 可复用的行业知识/方法论 | `docs/industry-knowledge/` |
| 跨项目可复用能力/技能 | `agent/_shared/`、`skills/` |
| 无价值/过时 | 删除 |

## 规范

1. **先进后转**: 收到的资料先复制/移入 inbox，再做归类，不直接散落
2. **及时清空**: 归类完成后从 inbox 移走，inbox 不长期堆积
3. **脱敏**: 客户敏感数据入库前脱敏（客户名/人员/密钥/真实编码替换）
4. **登记来源**: 进入 inbox 时记录来源与日期（可附在文件名或说明中）
