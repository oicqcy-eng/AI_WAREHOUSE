# knowledge — 项目专属知识

本项目交付过程中产生的**专属知识与决策**，只对本项目有效。

## 存放内容

- 项目关键决策记录（为什么这样设计）
- 项目专属的业务理解（现场工艺/流程特殊点）
- 需求 → 方案对应关系

## 与共享知识的边界

| 内容 | 放哪里 |
|------|--------|
| 本项目专属决策 | 本目录 |
| 可复用行业方法论 | `docs/industry-knowledge/` |
| 可复用能力/技能 | `agent/_shared/`、`skills/` |

## 规范

- 决策记录标注日期与负责人
- **交付结束提炼可复用经验**到共享层后，本项目可归档
