# knowledge — 项目专属知识

本项目交付过程中产生的**专属知识与决策**，只对本项目有效。

## 知识三件套

本目录用三个文件承载学习分析的产出（由 `archive-learning` 维护）：

| 文件 | 职责 |
|------|------|
| `file_index.md` | **资料索引**：本项目所有已归档资料 + 来源 |
| `knowledge_cards.md` | **知识卡片**：从资料提炼的五要素知识（业务对象/字段口径/接口规则/页面要求/待确认） |
| `pending_questions.md` | **待确认问题**：无法确定、需向客户确认的事项 |

## 与共享知识的边界

| 内容 | 放哪里 |
|------|--------|
| 本项目专属决策/卡片 | 本目录 |
| 可复用行业方法论 | `docs/industry-knowledge/` |
| 可复用能力/技能 | `agent/_shared/`、`skills/` |

## 规范

- **决策记录标注来源与日期**；知识卡片/索引一律注明来源文件
- **不捏造**：卡片要素缺的标"未获取"，问题待确认项如实登记
- **交付结束提炼可复用经验**到共享层后，本项目可归档
