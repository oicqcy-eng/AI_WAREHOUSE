# knowledge_cards — 知识卡片

> 从本项目资料中**提炼出的知识卡片**，供 Agent 检索复用。
> 每张卡片 = 业务对象 / 字段口径 / 接口规则 / 页面要求 / 待确认项 五要素，**注明来源**。

## 卡片模板

```
### K-xxx: <知识主题>
- **业务对象**: <核心业务实体>
- **字段口径**: <关键字段定义/单位/口径>
- **接口规则**: <接口路径/参数/协议>
- **页面要求**: <报表/看板结构/字段/更新频率>
- **待确认项**: <需向客户确认的内容>
- **来源**: <文件路径> · **日期**: <日期>
```

## 卡片列表

### K-001（示例）：排程需求要点
- **业务对象**: 生产排程
- **字段口径**: 工单状态(待排/已排/生产中/完工/关闭)
- **接口规则**: （示例）待从 ERP 确认排程数据接口
- **页面要求**: 排程看板需展示产能负荷率
- **待确认项**: 排程粒度（日/班次/小时）
- **来源**: `input/requirements/排程需求_v1_20260801.md` · **日期**: 2026-08-01

## 规范

- 一张卡片一个主题，编号 K-xxx 递增
- 五要素**缺的标"未获取"**，不编造
- 知识更新时补充新卡片，不覆盖历史
