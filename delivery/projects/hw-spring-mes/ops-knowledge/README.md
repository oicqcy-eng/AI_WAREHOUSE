## 规则

1. **只沉淀提炼后的排障卡 MD**；原始截图留本地 `inbox/日常运维报错截图/`，不入 git
2. **跨厂区共库的报错**（如 Home 共库各厂都有）→ 放本项目根级一张卡，标注涉及厂区；**厂区专属** → 卡内标注，可拆子目录
3. **同类报错复发** → 在对应卡上追加「复发记录」，不另建卡
4. 每次排查在 worklog 建任务（所属项目=`华纬MES项目`，类型=系统维护），卡上回填任务号
