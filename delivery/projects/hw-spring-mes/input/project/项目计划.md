**项目目标（4 项）**
> 顶层总目标（1.2 框架图）：**实现生产透明、质量可溯的标准化管理**——提升生产过程的透明化和数字化、提高"精细化管理"能力，形成全流程追溯体系·电子化。
> 三主轴-工具支撑：计划派工 → 智能车间 MES（生产透明化）；质量管理 → MES+QMS（过程检验）；设备管理 → MES（稼动管理）。
1. 接收生产计划分派任务，实时掌握工单生产过程信息 → 生产透明化、计划执行一体化协同（对应主轴 ① 生产透明化）
2. 实时掌握设备稼动信息 → 稼动率报表、保养计划、利用率分析（对应主轴 ③ 设备稼动）
3. 全流程质量电子化追溯（订单/工单/工艺/人员/设备/物料/首巡检质量数据）（对应主轴 ② 质量追溯）
4. 与 ERP 等系统集成对接 → 数据共享与业务协同（框架图外补充项）

## 三、整体方案规划概要

> 详细方案（参数规划表/机制流程/作业规划/接口清单/硬件点位）见 `raw/` 原件 PDF。

### 3.1 生产透明规划
- **透明化矩阵**：生产进度（派工/上下工/点检/eSOP/投入产出/重工/设备变更）、质量（首巡/不良处理）、设备（状态/稼动）、物料（领料校验/上下料）、异常（暂停/物料/设备/质量异常）五类透明 × 各工序
- **关键机制改变**：钉钉群派工 → MES 自动审核开批；手写流转卡 → 出站自动打印含二维码流转卡；手工记录 → 扫码进/出站报工、实时报表
- **作业规划**：上下工（工作平台+PDA）、上料（扫码校验，二期）、报工（进站/出站，PDA 简易报工含不良录入）

### 3.2 质量管理规划
- **过程检验**：首/巡/自/末检，扫流转卡检验、结果实时可查；不良信息经安灯推送钉钉
- **不良处理（例外处理）**：返工 / 让步 / 误判 / 报废入库 / 不良品入库，全程留档
- **质量追溯**：全链路批次追溯（每道作业站人员/时间/设备）

### 3.3 设备管理规划
- **设备稼动**：系统自动管理稼动状态，实时产出稼动信息、OEE
- **设备维保**：定期发起保养工单、执行叫修/维修/保养，消息推送钉钉
- **设备数采（IIOT）**：标准协议 MQTT，采集产量等实况，可自动执行生产报工

### 3.4 ERP-MES 业务交互（二期）
- **通道**：U9C ↔ ESB 中台 ↔ MES 双向
- **交互内容**：基础档案（工艺/仓库/库位/料件/部门/班别/设备/用户/客户/供应商）· 业务单据（销售订单/工单接收/生产订单/领料退料/工单领料信息）· 库存与状态（在线库存/在制库存扣减/物料批次绑定）· 质量（检验项目/首巡自检末检/PQC/报废入库）
- **关联**：U9 发料链路实现见 `agent/mes-implement-expert/data/u9-sql/`

### 3.5 硬件 / 数据 / 个案 / 大屏
- **硬件规划**：按车间工序点位部署工控机/PDA/平板/扫码枪/打印机/车间看板（华纬负责本地基础设施：数据库/应用服务器/网络/打印机/性能监控）
- **数据收集**：提供基础数据收集表格模板，按模板收集
- **个案规划明细**（二开）：手机端不良处理 / 出站打印逻辑变更（保留最小包装数功能） / 线边仓库管理 / 扫码查询状态 等，按实际发现收集
- **大屏看板**：设备看板 / 质量看板 / 综合管理看板 / 日管理看板

## 五、下阶段重点工作与风险应对

### 5.1 下阶段重点工作（5 项）
1. **现场硬件部署确认**：车间现场硬件环境部署到位，系统安装测试
2. **系统操作培训**：业务模拟剧本+考试机制，培训 sMES、帆软系统
3. **二次开发完成**：按功能差异完成个案开发与部署
4. **基础信息收集完成**：核心业务流程系统参数设置、基础资料导入、流程测试联调
5. **系统整合测试完成（二期）**：U9C 与 sMES 产品线整合应用测试与联调

### 5.2 风险与应对（5 类）

| 风险 | 应对 |
|------|------|
| 对规划流程不熟悉/有遗漏 → 基础数据配置偏差 | 建立基础数据检核机制，按时检查准备进度与正确性；各部门按规划流程讨论确认 |
| 人员投入时间精力不够 → 项目延期 | 做好项目细部计划，严格按时间节点推进 |
| 人员模拟运行不到位 | 项目组一致配合，管理上考核奖罚，顾问配合运行情况分析与问题处理 |
| 培训不认真 / 模拟上线不关心 | 汇总违规操作、生产执行操作考核；分批次加强培训 |
| 硬件采购滞后 | 硬件需求清单 + 到货时间跟踪 |
