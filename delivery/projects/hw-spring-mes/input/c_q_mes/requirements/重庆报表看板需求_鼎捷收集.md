# 重庆报表及看板需求（鼎捷方收集）

> 来源：`delivery/inbox/重庆华纬报表及看板需求.docx`（2026-08-16 归档）
> 用途：8-21 看板初版 + 报工报表四维度补齐的对焦依据；08-17 周例会与鼎捷确认范围
> 归属：重庆 sMES 项目（`input/c_q_mes/requirements/`）

## 一、报表（三张）

### 1. 生产日报
- 支持**按产线**（稳定杆、弹簧）查询；提供日期、工序、设备、工单、产品、人员等查询条件，**默认自动查询当天**
- 展示字段：工序、设备、工单号、产品编号、产品名称、产品规格、**批号数**（点击数据可显示具体批号）、进站、出站、累计出站、不良、良品、短少、多余、在制、待加工、状态、操作员、报工时间、昨日产量、差值
- **数据按【工序-工单-产品】层级聚合**：同一工序/工单/产品合并求和展示；任一项不一致则分行
- 筛选条件：【是否显示未加工批号】——展示归属该工序、尚未进站的产品数量
- **固定一行合计**：成品良品合计 / 不良合计 / 短少合计 / 多余合计 / 待加工合计
- **导出格式**：总表-子表格式——总表 = 两条产线数据；3 张子表 = 弹簧线、稳定杆线、工单对应批号明细

### 2 & 3. 增加两个报表
- 分别按**报工人员维度、工单维度**分组汇总，其余逻辑与生产日报一致

## 二、看板（生产看板 2 张 + 设备看板 1 张 + 质量看板 1 张）

### 1. 生产看板（弹簧线、稳定杆线各一张，6 项）
| # | 报表 | 说明 |
|---|------|------|
| 1 | 工序状态统计表 | 按工序（作业站）统计未开工/生产中/已完工产品数量 + 产品编号/数量/规格/批次明细 |
| 2 | 设备状态统计表 | 按设备统计未开工/生产中/已完工数量 + 明细，看单台设备负荷与在制 |
| 3 | 设备报工明细表 | 各设备进出站报工明细（产品编号/名称/规格/进站/出站/工序），追溯加工流转 |
| 4 | 24 小时产出趋势图 | 每整点产出量，口径 = **最后一道工序完工数量** |
| 5 | 近 7 天产出趋势图 | 近 7 日每日实际产出，口径同上 |
| 6 | 工序计划与实际对比图 | 双柱并列，每工序计划 vs 实际生产数量，看计划达成率 |

### 2. 设备看板（5 项）
| # | 报表 | 说明 |
|---|------|------|
| 1 | 设备稼动率统计表 | 按单台设备展示稼动率（备注：原"设备当前运行状态"调整为稼动率） |
| 2 | 近七日设备 MTTR & MTBF TOP8 | 平均修复时间 + 平均故障间隔，TOP8（备注：可沿用总部模板，需改数据源） |
| 3 | 近一个月设备异常稼动明细表 | 非计划停机/异常运行追溯 |
| 4 | 近一个月设备点检未通过明细表 | 点检 NG 设备整改跟踪 |
| 5 | 近七日故障不良柏拉图 | 故障不良原因分布 + 累计占比，定位维护优先级 |

### 3. 质量看板（7 项）
| # | 报表 | 说明 |
|---|------|------|
| 1 | 安灯原因发送消息记录表 | 安灯异常原因 + 消息发送明细（备注：沿用总部模板，需改数据源） |
| 2 | 一次通过率统计 | 生产全流程产品一次通过率 |
| 3 | 各工序质量指标统计 | 按工序统计良率/不良率/报废率 |
| 4 | 故障不良柏拉图 | 故障不良原因分布 + 累计占比 |
| 5 | 七日内首巡检记录查询 | 首件检验/过程巡检记录，可按条件追溯 |
| 6 | 近一个月不良原因柏拉图 | 不良项原因分布 + 累计占比 |
| 7 | 不良事件分析 | 典型不良事件专项分析（根因/改善措施/处理结果） |
