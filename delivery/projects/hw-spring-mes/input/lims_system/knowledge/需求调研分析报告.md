## 一、项目背景与目标

- **背景**：华纬科技现有实验室信息化管理已无法满足现阶段规模及业务发展需求，计划建设实验室信息化管理平台（LIMS）系统，提升业务流程规范性、数据完整性以及执行高效性。
- **编写目的**：定制软件开发细节，使开发工作更具体；说明功能需求、性能需求和数据需求，提供度量和遵循的基准。
- **范围**：深度融合 **ISO/IEC 17025:2017** 管理体系要求和赛印标准 LIMS 产品功能，结合华纬科技（诸暨）检测实验室业务流程，通过数字化手段实现实验室**人、机、料、法、环全要素**的精准控制与持续改进闭环。

## 三、总体设计原则（7 条）

统一设计、先进性、高可靠/高安全性、标准化、成熟性、适用性（急用先行、降成本）、可扩展性（降耦合、支持多格式数据存储）。

## 四、核心业务流程（4 条主流程）

### 1. 华纬检测业务流程（委托→报告全流程）
| 步骤 | 业务部门 | 岗位 | 关键活动 |
|------|---------|------|---------|
| 委托申请 | 品质部/研发部/工艺部/实验室 | 委托申请人 | 创建委托单，填写委托申请，提交 |
| 委托审批 | 实验室 | 技术负责人/检测负责人 | 审核通过或驳回 |
| 样品接收登记入库 | 实验室 | 样品管理员 | 审核委托基础信息、登记收样信息、生成样品编号、入库；支持驳回 |
| 检测任务分派 | 实验室 | 样品管理员 | 分派到指定检测人员；未接收可撤回重派 |
| 我的任务 | 实验室 | 检测人员 | 接收或驳回被分派任务（驳回可回到分派人或委托申请人） |
| 原始数据录入 | 实验室 | 检测人员 | 在线录入原始数据和检测结果，提交审核（可选审核人）；**原始数据录入模板有 34 个** |
| 数据审核（初审/复审/终审） | 实验室 | 检测人员/技术负责人/质量负责人（非录入人） | 审核通过/驳回 |
| 报告编制 | 实验室 | 报告编制人（检测人员） | 所有检测项目原始数据审核通过后编制报告 |
| 报告审核 | 实验室 | 报告审核人 | 通过/驳回 |
| 报告批准 | 实验室 | 报告批准人（授权签字人） | 签发最终报告 |
| 报告台账 | 实验室 | 实验室部门人员/文档管理员 | 报告归档和下载 |

**审核权限备注（关键）**：

- 疲劳实验室：复核人-**李旭敏**、终审人-**章海英**
- 样品编号带 **"XH"** 的检测项目需**三审**：初审-李旭敏、复审-章海英、终审-王燕春

### 2. 华纬样品管理流程
样品台账 → 样品收样（审核委托基础信息、登记收样入库）→ 样品领样（正常领样/复测领样）→ 样品出库（生成出库记录）→ 样品处置（直接归还或留样转余样库）→ **留样提醒（提前 3 天）** → 余样处置（到期归还/销毁）

### 3. 华纬报告变更流程
报告变更申请 → 审核 → 涉原始数据修改的：检测人员改数据（**系统日志记录留痕溯源**）→ 走原始数据审核→报告流程；仅基础信息修改的：直接改报告走审核流程。

### 4. 华纬委托变更流程
委托变更申请 → 审核 → 修改委托单基础信息 → 自动更新到后续该委托单所有信息。

### 2. 委托管理：委托申请（查询：车型代号/样品图号/委托人/委托状态/试验类型/客户编号/检测项目）、委托审核、委托台账（含下载委托单、基础信息变更）

### 5. 原始数据管理：原始数据台账（**删除需权限控制慎用**、变更驳回）、原始数据录入（待/已录入；**支持 pageoffice 录入**；提交选择审核人；继续流转）、初审/复审/终审（各分待审核/已审核）

### 7. 设备管理：设备台账（参考《试验机台账 20250828》）、设备保养（当月提醒+记录）、设备校准（计划申请→审核→批准→汇总→**提前一个月提醒**→结果审核→记录）、设备核查（同校准流程结构：申请→审核→批准→汇总→当月提醒→结果审核→记录）
### 8. 物料管理：物料台账、物料验收（待/已+审核）、物料入库（待/已；**物料码由 LIMS 生成**，标签参考 30mm*60mm，支持扫码入库、批量入库）、物料领用（**领用不做审核，耗品直接减库存；标物和化学品需要出库**）、物料出库（待/已，出库减一次库存）、物料领用台账（**归还后再增加一次库存**）、物料预警（低库存+有效期）
### 9. 人员管理：人员档案、人员资质、人员能力矩阵、人员培训（计划→审核→记录）、人员监督（计划→审核→记录，可上传附件）、人员监控（计划→审核→记录）
### 10. 质量管理：质量监督管理（计划→批准→提醒→记录）、质量监控管理（同结构）、客户满意度&投诉（满意度→批准；投诉记录）、内审管理（计划→审核→实施计划→审核→会议记录→检查记录-pageoffice→报告→不符合项整改计划→批准→整改记录）、管理评审（计划→批准→会议记录→输入材料→报告→改进项目→审批）、质控文件管理（质量手册/程序文件/实验室制度/作业指导书/技术记录文件/质量记录文件）
### 11. 数据采集：**10 台检测设备的集成**
### 12. 实验室环境温湿度记录：新增基础信息 + **传感器采集**
### 13. 统计分析管理：①按检测领域统计检查项目数量（**需李旭敏老师提供试验领域大类**）②按生产单位统计委托数量 ③按客户编号统计报告数量 ④按客户编号统计不合格报告和不合格检查项目数量 ⑤按检测人员统计检查项目（任务）数量
### 14. 基础数据管理：委托单位、检测项目（**备注：比亚迪/吉利客户，只有维护了对应客户代码，委托人才可选对应检测项目，否则视为未认可该项目**）、检测方法/标准、判定标准、检测方案、报告模板、原始数据模板、质量体系模板
### 15. 用户信息管理：组织管理、角色管理（**功能授权/接口授权/首页授权**）、岗位管理、用户管理（重置密码）
