# 一厂大簧报工查询（实例说明）

> **本文件是薄实例文件，不复制 SQL**——查询用通用模板跑，避免口径漂移。
> 通用模板：`agent/mes-implement-expert/data/smes-621-sql/今日设备报工查询-SQL.sql`（6 视角，2026-08-14 重庆模式通用化）。

## 运行方式

```bash
# 一厂大簧 = Home 共库厂区（192.168.200.18 / sMES_Home_Prod），--profile home
# prefix=101-01-DH 限定一厂大簧设备；date 指定日；date='' 跑全量（②/④适用）
node tools/query-mes.js agent/mes-implement-expert/data/smes-621-sql/今日设备报工查询-SQL.sql \
  --profile home -p prefix=101-01-DH -p date=2026-08-14 --show N
```

| 视角 | N | 说明 | date |
|------|:--:|------|------|
| ① 累计概览 | 1 | 报工/设备/生产批/工单/投入/产出/时段 | 指定日 或 '' |
| ② 按天分布 | 2 | 全量按日报工，看历史报工日 | ''（全量） |
| ③ 今日明细 | 3 | 设备×生产批×作业站逐条 | 指定日 |
| ④ 按工单汇总 | 4 | 工单/产品/设备数/投入/产出 | 指定日 或 '' |
| ⑤ 按人员统计 | 5 | 工号/姓名/次数/投入/产出（**共库已带 prefix 限定**） | 指定日 或 '' |
| ⑥ 按设备汇总 | 6 | 设备/设备名/次数/生产批/工单/投入/产出 | 指定日 或 '' |

## 一厂大簧判定口径

- **设备归属**：`EQUIPMENTNO` 前 10 位 = `101-01-DH` → 一厂大簧（229 台）；**没有该前缀 = 二厂大簧设备**
- **弹簧流程佐证**：`PROCESSTYPE = N'弹簧流程'`（大簧小簧均为弹簧流程，作辅助确认）
- **工序码映射**（2026-08-14 报工实测，见知识卡）：C02 回火 / C03 强压缩(一) / C06 抛丸(0.9+0.7mm) / C08 负荷分组 / C09 热压缩 / H03 热卷 / C01 卷簧

## 注意

- 共库多厂区并存，⑤⑥ 视角模板已内建 prefix 限定，**查询时 prefix 必须正确传参**，否则会统计进其他厂区
- 明细视角（③）对 `date=''` 会慢且数据量大，默认按指定日跑
- 报表输出按通用规范：`agent/mes-implement-expert/data/smes-621-sql/厂区报工报表规范.md`
