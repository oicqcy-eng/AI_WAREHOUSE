## 控制计划（CP）标准作业流

> 2026-09-08 用户确立：后续控制计划"没什么情况就按这个模式"。

1. **模板基准**：以 F-018 的 7 份最新 CP（陈海林 9-8 版）为标准格式模板；新产品 CP 照此模式整理。
2. **生成**：用控制计划转换工具 v4.5（F-025，解析逻辑见知识卡 K-014）跑 CP → 产出 **SIP 导入文件（.sql/.xlsx）+ 产品流程文件（.xlsx）**（生成物形态见 F-019/F-023/F-024）。
3. **导入 MES**：SIP/产品流程文件导入 sMES（QMS 检验项 + 工艺流程）。
4. **已知坑**（K-013/K-014）：XH_C05 超声波清洗段"Follow 母表"特性易落计数（规格文本正则接不住单位前置 `~`、时间无模式、复合配方等）；清洗参数以母表 F-022（HW/WI-22-09-14/A1）为准。生成后需核对清洗段是否误判计数。
