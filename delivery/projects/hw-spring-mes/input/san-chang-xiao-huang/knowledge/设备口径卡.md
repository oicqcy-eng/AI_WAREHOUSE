# 三厂小簧设备口径卡（2026-08-23 实测）

> 来源：Home 共库 `sMES_Home_Prod` 实测（`--profile home`，报工实测 + 设备主数据）+ 客户台账知识卡（K-002/K-004/K-006）。
> 用途：判定设备归属三厂小簧、构造厂区限定查询条件、解读报工报表工序码。数据低频变化，可随时重跑验证。

## 设备归属判定

| 判定 | 条件 | 数量 |
|------|------|:---:|
| **三厂小簧（主体）** | `EQUIPMENTNO` 以 `X` 开头（**XA/XB/XC/XE/XF/XH/XJ/XM/XO/XP/XQ/XS/XT/XY** 14 系） | **212 台**（库内 2026-08-15 实测） |
| **三厂小簧（起重机）** | `HA-Q*`/`HC-Q*`/`GP*` 电动桥式起重机（按「设备类别」判定） | 6 台 |
| **三厂小簧（合计）** | — | **218 台** |

- ⚠️ **前缀非唯一**：仅凭 X 前缀不够准确判定厂区，**以「设备类别」列 = 华纬三厂（小簧）为准**（`XA` 系也覆盖非报工设备，如 XB 系油烟净化器/磷化除渣机）；报工查询用 `X%` 前缀可覆盖报工设备，起重机无报工
- **其他厂区判定**见总表：[设备编号前缀-厂区映射](../../../../../agent/mes-implement-expert/data/smes-621-sql/设备编号前缀-厂区映射.md)

## 工序编码映射（客户工序清单 K-004，2026-08-04）

| 段 | 工序编号 | 工序名 |
|:---:|------|------|
| 检验 | Q1 / Q2 / Q3 / Q4 / Q5 | 来料检验 / 过程自验 / 过程巡验 / 成品检验 / 周期性检验 |
| 前段 | A01 / A02~A07 / A08 | 卷簧 / 成型1~6 / 卷簧放钢丝 |

> **「工序标黄 = 制样截止工序」**（模拟剧本制样批报工到该工序止）。

## 报工数据形态（2026-08-23 实测，`--profile home -p prefix=X`）

- **报工未启用**：`X%` 共库报工历史仅 **30 条 / 11 设备 / 14 生产批 / 10 个报工日**（2026-06-09 ~ 2026-07-23），**8 月起无报工**——正值 9/7~9/11 全流程模拟筹备期（K-008），报工随模拟启用
- 历史报工日均为**零星联调/测试量**（单日记录 1~11 条、投入 7~16000、产出多为 0 或极小；7-07/7-08 大投入 15900/16000 产出 17/150，典型测试批）——**勿当作正式生产量解读**
- 对比一厂大簧（同日 27 条 / 80,244 产出）与重庆（8-22 投入 2,398），三厂当前处于"通道就绪、数据未生产"状态

## 通用口径（与重庆/一厂一致，2026-08-14 定版）

- **本次投入/产出** = `TBLWIPCONT_EQUIPMENT.InputQty/OutputQty` = `TBLWIPLOTLOG_REPORT.INPUTQTY/(GOODQTY+FAILQTY)`；**`TBLWIPCont_Resource.INPUTQTY` 是资源加工量，勿用于投入统计**
- **进行中报工**：`TBLWIPLOTLOG_REPORT.ENDTIME IS NULL`
- **报工人员**：`TBLWIPCont_Resource.USERNO`（姓名映射 `TBLUSRUSERBASIS`）；**参与人员 = RESCLASS 0∪1 去重**（口径B：报工的人也是一起作业的，用户确认；RESCLASS 语义见一厂口径卡 2026-08-23 修正版）
- **共库人员限定**：⑤按人员统计必须限定 `LOGGROUPSERIAL ∈ (X% 设备报工组)`，通用模板已实现
- **系统代报**：`USERNO='DS'` = 系统管理员代报
