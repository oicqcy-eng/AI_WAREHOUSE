# 三厂小簧报工查询（实例说明）

> **本文件是薄实例文件，不复制 SQL**——查询用通用模板跑，避免口径漂移。
> 通用模板：`agent/mes-implement-expert/data/smes-621-sql/今日设备报工查询-SQL.sql`（7 视角，重庆模式通用化）。

## 运行方式（命令行，AI/脚本用）

```bash
# 三厂小簧 = Home 共库厂区（192.168.200.18 / sMES_Home_Prod），--profile home
# prefix=X 限定三厂小簧设备（X 系为主；⚠️ 结合设备类别=华纬三厂(小簧)，见 设备口径卡）
node agent/mes-implement-expert/tools/query-mes.js agent/mes-implement-expert/data/smes-621-sql/今日设备报工查询-SQL.sql \
  --profile home -p prefix=X -p date=YYYY-MM-DD --show N
```

| 视角 | N | 说明 | date |
|------|:--:|------|------|
| ① 累计概览 | 1 | 报工/设备/生产批/工单/投入/产出/时段 | 指定日 或 '' |
| ② 按天分布 | 2 | 全量按日报工，看历史报工日 | ''（全量） |
| ③ 今日明细 | 3 | 设备×生产批×作业站逐条 | 指定日 |
| ④ 按工单汇总 | 4 | 工单/产品/设备数/投入/产出 | 指定日 或 '' |
| ⑤ 按人员统计 | 5 | 工号/姓名/次数/投入/产出（**共库已带 prefix 限定**） | 指定日 或 '' |
| ⑥ 按设备汇总 | 6 | 设备/设备名/次数/生产批/工单/投入/产出 | 指定日 或 '' |
| ⑦ 跨天收口 | 7 | 当日出站但非当日新开批（看当天实际交付） | 指定出站日 |

## 三厂小簧判定口径

- **设备归属**：`EQUIPMENTNO` 以 `X` 开头（XA/XB/XC/XE/XF/XH/XJ/XM/XO/XP/XQ/XS/XT/XY 14 系）→ 三厂小簧主体（库内 212 台）；另 6 台非 X 前缀桥式起重机（`HA-Q*`/`HC-Q*`/`GP*`）需按「设备类别」= 华纬三厂（小簧）补入——**报工查询用 `X%` 前缀即可覆盖报工设备**，起重机无报工
- **⚠️ 前缀非唯一**：仅凭 X 前缀判定厂区，准确判定以**「设备类别」列 = 华纬三厂（小簧）**为准（见 [`设备编号前缀-厂区映射.md`](../../../../../agent/mes-implement-expert/data/smes-621-sql/设备编号前缀-厂区映射.md)）
- **工序/流程佐证**：小簧单元工序清单 A 段卷簧/成型 + B 段退火/磨削/喷丸（见 `knowledge/设备口径卡.md`）

## 当前状态（2026-08-23 实测）

- ⚠️ **报工未启用**：三厂小簧 `X%` 在共库报工历史仅 **30 条 / 11 设备 / 14 生产批**（2026-06-09 ~ 2026-07-23），**8 月起无报工**——正值 9/7~9/11 全流程模拟筹备期（K-008），报工随模拟启用
- 历史报工日 10 天，均为零星联调/测试量（投入 7~16000，产出多为 0 或极小）；**9/7 模拟启用报工后，本说明 + 通用模板即可直接跑当日报表**
- 报表输出按通用规范：`agent/mes-implement-expert/data/smes-621-sql/厂区报工报表规范.md`

## 注意

- 共库多厂区并存，⑤⑥ 视角模板已内建 prefix 限定，**查询时 prefix 必须正确传参**，否则会统计进其他厂区
- 明细视角（③）对 `date=''` 会慢且数据量大，默认按指定日跑
- 报工启用前查询结果均为历史联调数据，勿当作正式生产量解读
