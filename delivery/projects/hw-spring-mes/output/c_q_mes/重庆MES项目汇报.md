# 华纬汽车零部件（重庆）MES 项目汇报

> 数据截至：2026-08-13 · 编制：华纬 MES 实施运维组 · 受众：总监

## 一、项目背景

华纬集团（深交所 001380，国内弹簧行业前三）推进制造数字化建设，MES 为集团统一数字化主线：**集团内分厂区、分期实施**（一期华纬稳定杆项目 2024-2025 已落地；三厂小簧、一厂大簧、重庆为扩展实施）。

**重庆** = 华纬汽车零部件（重庆）有限公司，2026 年 3 月启动 sMES 实施，沿用集团统一鼎捷 sMES 体系，与总部 U9（ERP）集成，覆盖弹簧、稳定杆产线。

## 三、总体实现要求

> 借鉴集团一期稳定杆项目目标框架 + 鼎捷服务 3.0 实施方法论（M1 启动→M2 机制流程规划→M3 流程和数据验证→M4 实施运行→M5 运行成果总结）。

1. **计划执行一体化**：MES 接收生产计划、自动分派任务，实时掌握工单生产过程，实现计划执行协同
2. **生产过程透明化**：扫码进站/出站报工、生产进度实时可查、异常安灯预警
3. **质量电子化**：检验流程电子化、全链路批次追溯（订单/工单/工艺/人员/设备/物料/首巡检）
4. **设备数采**：IIOT 平台实时采集设备产量、工艺关键参数、设备状态，支撑稼动率/OEE
5. **ERP 集成**：与 U9（U9C↔ESB↔MES）工单、物料、仓库、领料接口对接，数据共享协同
6. **数据基础扎实**：四大基础资料（物料/设备/人员/检验）规范收集导入，贯穿各阶段
