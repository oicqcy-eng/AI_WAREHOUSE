# 仓库管理模块

> **模块说明**: 出入库管理、库存盘点、库位管理、库存移动、库存预警
> **服务端口**: 8072 (HTTP)
> **数据库**: warehouse_db

## 功能范围
- 入库管理 (采购入库/生产入库/退货入库)
- 出库管理 (生产领料/销售出库)
- 库存盘点 (周期盘/年终盘)
- 库位管理 (库区/货架/库位)
- 库存移动与调拨
- 库存预警 (安全库存/呆滞料)
- 条码扫描出入库

## 快速操作
```bash
docker compose -f deploy/docker-compose.yml up -d
curl http://localhost:8072/health
```
